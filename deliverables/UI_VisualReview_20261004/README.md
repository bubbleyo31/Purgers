## 已確認：血格規則

使用者確認：每格 20 HP 時連續受到 8、7、5 傷害，實際 HP 即時扣除，血格前兩次不變，累積 20 才減一整格。補血同樣累積滿一格才亮回。

- 不顯示半格／水平切片；只改本機表現，不量化真實傷害或治療。
- 護盾接在目前顯示的血格後方，同排、同高度、同間距，不留最大生命空格造成的空段。
- 以 Overwatch 2 的窄血格作形狀參考。扣／補動效是待確認提案，未宣稱量測或重現原遊戲時序。
- 只做獨立動畫與操作預覽，**不得操作 Unity 或改寫遊戲腳本／Scene／Prefab**。

## 血量動態預覽提案（待視覺確認）

- 每格暫用既有 20 HP；高血量保持相同單位，在固定可用寬度內縮窄格寬／間距，不換行、不溢出。
- 數字即時更新；生命／護盾各有正負餘額累積器，跨正／負一格閾值才變格。反向治療先抵銷尚未成格的傷害。
- HP／護盾歸零時清掉該類全部格；補滿 HP 時回復全部格。非整除池的尾數以完整格表現、數字保留精確值；端點處理仍為提案。
- 受傷：被移除的整格短暫暖紅殘影，約 80 ms 停留後整格淡出，總長約 300 ms，不切碎片。
- 治療：整格出現，約 260 ms 淡綠亮回暖米白，不橫向填滿。
- 護盾：淡金色、與生命共用步距；低 HP 警示不染紅護盾。
- 動效時序／色彩是 Purgers 提案，不是 Overwatch 2 官方參數。
