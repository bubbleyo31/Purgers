## 2026-09-30 Attack Rifle／Support SMG 後座力施加平滑（局部核對）

核對來源：`Assets/Scripts/Weapon/Attack/AttackRifle.cs`、`Assets/Scripts/Weapon/Support/SupportSMG.cs`、`Assets/Scripts/Weapon/WeaponRecoilApplication.cs`、兩份 Profession Runtime Prefab。原本每發透過 `PlayerMovement.AddLookRotationImpulse` 一次加入 KCC；只有停止射擊後的回正按 Tick 分段。現在射擊總角度先存入各武器的 Fusion `[Networked]` 待施加量及剩餘時間，每個 `Simulate` Tick 最多施加一次。`WeaponRecoilApplication.Step` 按「本 Tick 秒數 ÷ 剩餘秒數」取出該 Tick 的 Pitch／Yaw，最後一 Tick 結清，總角度保持不變；0 秒當 Tick 全部施加。新一發會與未施加的角度合併，重新從完整施加時間分段。命中仍以該發射擊前的準心方向判定；分段抬槍會影響後續射擊。

設定位置：`Assets/Prefabs/ProfessionRuntime/AttackProfessionRuntime.prefab` 根物件 **Attack Rifle**，以及 `Assets/Prefabs/ProfessionRuntime/SupportProfessionRuntime.prefab` 根物件 **Support SMG**。兩份分別調整。以下為 Unity Editor 實際讀到的 Prefab 值（Attack／Support）；新欄位的程式預設亦為 0.06 秒。

| Inspector 欄位 | Attack／Support 現值 | 有效範圍、單位與作用 |
| --- | --- | --- |
| 遊戲邏輯 後座力 → Recoil Pitch Per Shot | -1／-0.8 | 度／發；負值向上，正值向下。無程式限制；自動回正目前只追蹤負值。 |
| 遊戲邏輯 後座力 → Recoil Yaw Per Shot | 0.15／0.25 | 度／發；`[Min(0)]`，左右交替，0 關閉水平後座力。 |
| 後座力施加設定 → Recoil Application Duration | 0.06／0.06 | 秒；`[Min(0)]`，0 為瞬間施加。大於 0 則按 Fusion Tick 分段；沒有硬性上限，過大會讓連射角度堆積、準心反應延後。 |
| 後座力回正設定 → Recoil Recovery Delay | 0.1／0.15 | 秒；`[Min(0)]`，從最後一發起算，且待施加角度完成後才可回正。 |
| 後座力回正設定 → Recoil Recovery Speed | 20／20 | 度／秒；`[Min(0.1)]`，每 Tick 最多回正 `速度 × Runner.DeltaTime`，只回正尚未被手動壓槍抵消且已實際施加的向上角度。 |

調整步驟：在對應 Prefab 選根物件的武器元件，先只調 **Recoil Application Duration** 並儲存。建議從 0.04～0.08 秒試起；例如從 0.06 改為 0 時可對照原本瞬間跳動，改為 0.1 秒會更柔和但可能跨到下一發。這些是試調例子，不是程式限定範圍。若要調的是停火後回落，改 **Recoil Recovery Delay／Speed**，不要誤用施加時間。`recoilPitchPerShot` 的絕對值、施加時間與射速共同決定連射時的視角反應；時間超過射擊間隔時，多發會合併分段。

儲存 Prefab 後，重新生成對應 Profession Runtime 才會使用新設定；Play Mode 中直接改 Clone 只供當次測試，不寫入存檔。Host／Input Authority 依 Fusion 預測及權威模擬各自施加 Gameplay 視角，未新增 RPC；其他玩家不應看到本機視角變化。Support 空中特殊模式不新增後座力，進技能前尚未施加或正在回正的角度仍會處理。

Play Mode 檢查：分別用 Attack／Support 普通射擊，先設 0 秒確認瞬間抬槍，再設 0.06 秒確認數個 Tick 逐步抬槍且最終角度相近；連射時檢查準心與下一發落點、停火後回正及手動下壓不被二次拉回；Support 特殊模式射擊不新增後座力。需在獨立 Host／Client 各自操作與觀察，Editor EditMode 測試不取代這項實測。

## 已確定規則

### 2026-10-01 顯示延遲裁切隱藏路段（目前規則）

`Display Delay` 仍讓線段生成後正常飛行，但延遲期間飛過的路段永久不予繪製。到達開放時間的位置成為固定繪製起點；可見線段從此逐漸長出，達到 `Tracer Length` 後尾端再跟隨前端。跨越開放時間的影格內會計算實際位置，不使用整個影格結束的位置代替。生命期、命中隱藏及每發滿動能色彩取樣沿用原規則。

固定速度時，起點距離 `S = Travel Speed × Display Delay`，可見尾端距離為 `max(S, Head Distance − 有效線長)`，且不得超過前端；零長度不啟用 Renderer。例如速度 100、延遲 0.1、線長 2：0～10 公尺不畫；前端 10.5 時畫 10～10.5，前端 11 時畫 10～11，前端 13 時畫 11～13。Inspector 仍在兩份 Profession Runtime Prefab 根物件的 Bullet Tracer Line Drawer → 飛行設定 → Display Delay，範圍 ≥0 遊戲秒、程式預設 0，不新增欄位。

若整段飛行在開放前已完成，沒有新的可見路段，停留與淡出階段也不補畫。`Animate Travel` 關閉或速度 ≤0.01 時原本直接放到最終位置；搭配正延遲不會長出任何線段，需設 Delay 為 0 才顯示既有靜態線段。手動驗收可暫設速度 100、Delay 0.1、線長 2，向超過 20 公尺的目標射擊，確認從 10 公尺處長出而非瞬間出現整段 2 公尺；完成後自行恢復參數。

本輪加強起點／長滿後尾端與最終停留裁切的 EditMode 案例；Unity MCP 無可用 session，refresh 等待就緒逾時，未能執行本輪編譯、聚焦測試及完整回歸。以下歷史通過數不能作為本版結果；詳見 [130](130_回歸驗證與審查狀態.md)。

### 2026-09-26 滿動能 Tracer 換色

`BulletTracerLineDrawer` 在每發生成時，從所屬 `PlayerProfessionRuntime.OwnerPlayer` 取得 `PlayerGrappleMomentumEnergy.NormalizedEnergy`。滿值 `>= 1` 時以 `Maximum Energy Tracer Color` 取代一般 `Tracer Color`，仍與現有 `Tracer Gradient` 相乘。此處「速度加成滿級」指鈎索動能量條滿值，不是世界移動速度或玩家經驗等級。最高強化保持期間動能維持 1，所以繼續使用強化色；低於 1 後的新發射恢復一般色。

位置：兩份 `Assets/Prefabs/ProfessionRuntime/AttackProfessionRuntime.prefab`／`SupportProfessionRuntime.prefab` 根物件的 **Bullet Tracer Line Drawer → 外觀設定**。

| 欄位 | 新增預設 | 作用 |
| --- | --- | --- |
| Use Maximum Energy Color | 開啟 | 關閉時所有新線段使用原本 Tracer Color。 |
| Maximum Energy Tracer Color | RGBA `(0.2, 0.8, 1, 1)`，青色 | 滿動能的基礎色，色票 RGB／Alpha 0～1；最終色彩與透明度仍受 Tracer Gradient 及材質影響。 |

保留現有 Prefab／Scene 設定，不需手動指定玩家引用。讀取來源前先檢查 Runtime、Player 及動能的有效網路狀態；來源缺少或未 Spawn 時安全回到原色。此元件只讀取資料，傷害、充能與同步仍由原系統處理；無新 RPC／Networked 欄位。

每發顏色取生成時的動能，隱藏延遲／飛行／淡出期間不因動能下降而變色。修改 Prefab 後儲存並重新生成 Runtime；Play Mode 改 Clone 只影響後續射擊，不會寫入存檔。

驗收：一般動能射擊應為原色；利用鈎索充滿量條後射擊應使用強化色；最高強化結束、動能低於滿值後再射擊應恢復原色。以白色 Tracer Gradient 檢查原色差異最直接；如漸層含純紅，乘上青色可能偏暗。兩把槍各測一次，Host／Client 各自觀察自己的線段。聚焦 EditMode 12／12 通過（含 0、0.999、1、退回半滿、停用與未 Spawn）；實戰充能射擊、獨立 Host／Client 仍待驗證，完整回歸見 [130](130_回歸驗證與審查狀態.md)。

### 2026-09-25 BulletTracer 線段顏色與透明度漸層

局部核對來源：`Assets/Scripts/Weapon/BulletTracerLineDrawer.cs`、兩把槍的 `ShowLocalBulletTracer` 及兩份 Profession Runtime Prefab。Tracer 仍只顯示 Input Authority 自己的第一人稱射擊；Hitscan、命中、傷害與網路權威不變。本次未改 Scene／Prefab 參數或引用。

修改位置：開啟 `Assets/Prefabs/ProfessionRuntime/AttackProfessionRuntime.prefab` 或 `SupportProfessionRuntime.prefab`，選根物件的 **Bullet Tracer Line Drawer → 外觀設定**。兩份 Prefab 分別調整。

| Inspector 欄位 | 目前值／預設值 | 範圍、作用與相依關係 |
| --- | --- | --- |
| Tracer Color | 兩份 Prefab 為 RGBA `(1, 0.5151677, 0, 1)`；新元件預設 `(1, 0.85, 0.25, 1)` | 基礎乘色。RGB 與 Alpha 有效值 0～1；要直接顯示漸層原色，設為白色 `(1, 1, 1, 1)`。 |
| Tracer Gradient | 新增；既有兩份 Prefab 載入後為全白、Alpha 全 1 | 線段尾端為左邊 0，前端為右邊 1。色鍵改 RGB、透明度鍵改 Alpha（0～1），可加入多個鍵點。預設保留舊橘色外觀。 |
| Tracer Material | 兩份 Prefab 均為空 | 留空沿用 `Sprites/Default`；自訂 Shader 必須讀取頂點色並支援透明混合。材質的色彩／貼圖可能再次調色或降低透明度，不能保證任意 Shader 都接受上述設定。 |
| Fade Duration | 兩份 Prefab 均為 `0` 秒；新元件預設 `0.04` 秒 | ≥0；0 不淡出。只在整段飛行後且 Renderer 尚未因穿過命中點而隱藏時生效。 |
| Display Delay | 程式預設 `0` 秒 | 位於「飛行設定」，≥0 遊戲秒；決定永久隱藏的前段路徑。線段照常飛行，從開放時間的位置開始長出，尾端不回補隱藏路段。已通過命中點而隱藏或生命期結束時不再顯示。 |

線段每點 RGB = `Tracer Color RGB × Tracer Gradient 在該位置的 RGB`；每點 Alpha = `Clamp01(Tracer Color.a × 漸層 Alpha × 淡出剩餘比例)`。材質／貼圖另有乘色時也會影響最終畫面。每發建立時取樣外觀，並立即開始飛行；`Display Delay = 0.1` 代表前 0.1 遊戲秒隱藏，但位置正常前進。固定速度下，第一次顯示的前端約在 `Travel Speed × Display Delay` 距離處，受影格時間及最遠視覺距離限制。停留與淡出照原時間進行，且保留可繪製起點裁切；若飛行結束時尚未長出可見線段，後續不再補畫。Inspector 修改從下一發生效。若在延遲結束前就因穿過命中點而隱藏或生命期結束，該發全程不可見。LineRenderer 色彩可能有約 1／255 的量化誤差。兩個端點使用 12 個 Cap Vertices 形成較平滑的圓角。

操作與 Play Mode 檢查：

1. 在對應 Runtime Prefab 把 `Tracer Color` 設成白色、Alpha 1；打開 `Tracer Gradient`。例如尾端色鍵設橘色、前端色鍵設青色；尾端 Alpha 鍵設 0.1、前端設 0.8。儲存 Prefab 後重新進入遊戲。
2. 使用該職業射擊，預期線段尾端近透明橘色、前端較明顯的青色。把兩端 Alpha 都設 0，整段應不可見；彈藥／命中／傷害仍照常發生。
3. 遊戲中臨時調整時，選本機玩家的 `AttackProfessionRuntime(Clone)`／`SupportProfessionRuntime(Clone)`。設定從下一發生效；Play Mode instance 調整不會自動存回 Prefab，也不寫入遊戲存檔。
4. 若要單獨觀察淡出，可暫時關閉 `Hide After Passing Hit Point`，設定 `Visible Duration = 0.03`、`Fade Duration = 0.1` 秒。這會讓彈道在命中點後方停留，僅作外觀檢查；原設定開啟隱藏時，不應期待結尾淡出可見。
5. 既有 Attack／Support 的 `Travel Speed` 為 5000／2400 世界單位每秒，`Tracer Length` 為 10／20；近距離可能一幀飛完整段並隱藏。若需要檢查顏色，可暫時將速度降至 250（實際飛行需 >0.01），確認後再自行調回；本次未代改速度。
6. Host／Client 各自驗證本機職業；不期待看到對方的 Tracer，也不會透過網路同步 Inspector 外觀設定。
7. 檢查時可暫設速度 100、`Display Delay = 0.1`，向超過 20 世界單位的目標射擊：線段從生成就飛，約 0.1 秒後從距槍口 10 世界單位的位置開始長出；此前路段永遠不畫。改成 0 時立即可見；延遲大於生命期時全程不可見。原 Attack 速度 5000 配 0.1 秒會隱藏前約 500 世界單位，較近目標可能完全看不到。觀察兩端圓角時可暫時加大寬度；完成後自行恢復參數。

聚焦 EditMode 7／7 通過，涵蓋隱藏期間位移、在當前位置顯示、穿過命中點後不重新顯示、漸層與圓角。完整回歸及編譯狀態見 [130](130_回歸驗證與審查狀態.md)。尚未完成實戰畫面、Build 或獨立 Host／Client 驗證。

### 既有武器規則

- Attack Rifle 與 Support SMG 換彈期間都不能進 Aim。
- Aim 動畫正播到瞄準姿勢；取消 Aim 以負速度倒播。
- Aim 後停用的是 ViewModel 的 Idle Motion、Walk Bob 等程序位移，不是把整個 `FirstPersonViewModelMotionProfile` 永久改為零或停用所有表現。
- 武器 Networked 屬性只能在 `Spawned()` 後讀取。ViewModel 切職業時若新武器尚未 Spawn，必須安全等待。
- 槍聲需要讓其他玩家聽見時走 `NetworkPlayerAudioEmitter`，而且 One Shot 必須跟隨射手，避免玩家移動後聲音留在舊世界座標。
- Animation Event 的拉槍機等細節音只給本機第一人稱，不進世界廣播。

2. 彈藥 HUD 實作 `IPlayerWeaponHUDSource`。
3. 傷害仍產生 `DamageRequest`；不要另建扣血流程。
4. 世界聲音走 Network Emitter，本地機械細節走 Animation Audio Events。
5. ViewModel 動畫只讀武器公開狀態，並處理尚未 Spawn 的安全條件。
