# 槍械命中特效與彈孔

最後核對日期：2026-09-25（本功能局部核對）  
核對來源：`Assets/Scripts/Weapon/Core/PlayerWeaponImpactEffects.cs`、`WeaponImpactSettings.cs`、`WeaponImpactVisuals.cs`、`Attack/AttackRifle.cs`、`Support/SupportSMG.cs`。  
相關文件：[50 武器](50_武器瞄準與射擊.md)、[20 玩家](20_玩家核心移動與狀態.md)、[驗證紀錄](Validation/WeaponImpacts/README.md)。

## 狀態與權責

程式、三款材質及設定資產已提供；玩家 Prefab 尚待手動掛載。本次未修改 Scene／玩家或武器 Prefab，未完成獨立 Host／Client 實戰驗收。

使用者指定所有玩家可見。資料流為：

```text
AttackRifle／SupportSMG：State Authority 正式 Hitscan → ProcessHit
→ Owner Player Root 的 PlayerWeaponImpactEffects.PublishConfirmedHit
→ Reliable StateAuthority → All RPC（含 Host 本地）
→ 各接收端該射手專屬 WeaponImpactVisuals
→ 有限容量彈孔＋播放後清除的 Spark
```

只消費正式命中，沒有左鍵監聽、客戶端預測命中或第二套傷害。治療 SMG 也按照實際命中 Layer 判斷視覺，與傷害／治療是否成功無關。效果不影響武器 `hitMask`、傷害、治療、Action Gate 或 Tracer。

RPC 攜帶命中點、法線、Layer、變體與角度；網路表面另帶 NetworkId 和相對位置／法線。Host 按射手遞增序號選變體，接收端去重，不消耗 Gameplay 的隨機狀態。沒有歷史 `[Networked]` 彈孔清單：晚加入／重連只接收之後的新命中，不補播舊孔與火花。須讓玩家 NetworkObject 對應接收端保持可見；若未來加入 AOI，需另外處理跨興趣範圍呈現。

## 手動設定順序

1. 停止 Play Mode，開啟 `Assets/Prefabs/KCC_Player.prefab`。
2. 在具有玩家 `NetworkObject` 的根物件新增 `PlayerWeaponImpactEffects`，保持啟用。不要放進 Attack／Support ProfessionRuntime，也不要在 Spawn 後動態新增 NetworkBehaviour。
3. 將 `Settings` 指到 `Assets/Art/VFX/BulletHoles/WeaponImpactSettings.asset`。Prefab 儲存後讓 Fusion 正常重新匯入／烘焙。所有 Host／Client 使用相同新版玩家 Prefab 與設定。
4. 確認設定的三個 `Bullet Hole Materials` 順序為 Compact、Radial、Fractured；已排除 Oblique，原圖仍保留。
5. 確認 `Spark Prefab` 為 `Assets/Art/VFX/SparkOnWall_vfx/Spark_vfx.prefab`。此引用已寫入新設定資產。
6. 檢查真正被命中的 Collider／Hitbox 所在物件 Layer。兩個視覺遮罩預設只勾 `Default`。
7. 主遊戲世界相機必須看得到 `Default`。生成物是世界視覺，不使用 ViewModel 相機；不需 URP Decal Renderer Feature。

目前 Editor 核對：敵人 Core、Boss、Melee A/B、Ranged A/B 的碰撞／Hitbox 在 `9: Hit Mask`；MapChunk Boss、Prototype、阻擋屋的碰撞體在 `0: Default`。因此預設排除這些敵人本體。場景 instance overrides 或未列出的物件仍須檢查；敵人投射物 Prefab 是 Default。專案目前沒有名為 Enemy 的 Layer。不要只修改敵人父物件而忘記實際 Hitbox，也不要把視覺遮罩當成武器命中遮罩。

## Inspector 調整

調整入口為上述 `WeaponImpactSettings.asset`，不是槍口火焰元件。建議停止遊戲後調整，確保各端設定相同。

| 欄位 | 初始值／範圍 | 效果與驗證 |
| --- | --- | --- |
| Bullet Hole Layers | Default；任意 LayerMask | 哪些命中層留下孔；Nothing 停用。排除 Hit Mask 後打敵人仍可造成傷害但沒有孔。 |
| Spark Layers | Default；任意 LayerMask | 獨立控制火花；可只留下孔或只播火花。 |
| Max Bullet Holes Per Player | 32；1～128 | 每名射手、每個接收端的孔上限。降低時下一幀裁掉最舊孔；切 Attack／Support 共用。 |
| Bullet Hole Size | 0.2 公尺；0.01～2 | 整張貼圖世界邊長，包含透明區。只影響新孔；在牆面觀察尺寸。 |
| Surface Offset | 0.002 公尺；0.0005～0.03 | 沿表面法線外移，避免 Z-fighting；太大浮空。新孔生效。 |
| Max Sparks Per Player | 12；1～32 | 同時活躍火花上限；超量立即停用並銷毀最早的一個。 |
| Spark Scale | 1；0.01～10 | 整體倍率，保留素材內部相對比例。新火花生效。 |
| Spark Timeout | 15 秒；0.1～30 | 遊戲時間的最長存活保險；一般粒子結束會提早清除，太短會截斷。 |
| Spark Rotation Offset | (0,0,0)；Euler 度數 | 預設素材 +Z 朝法線外側；若素材方向改變才修正。 |

## 清理、效能與表面限制

每個射手一個本地容器、共享 Quad 與材質；生成物沒有 Collider。容量按玩家根物件生命週期計算，換槍／切職業不重置。玩家 Despawn、元件停用／銷毀、所在 Scene 改變或更換 Settings 時清空。孔沒有額外倒數壽命；超量、表面銷毀／停用或玩家清理才消失。N 名玩家的上限為 N×32 個孔及 N×12 組火花（預設），不是整場全域 32。

靜態表面由接收端同 Runner PhysicsScene 在權威點附近短距離辨識，只取得跟隨 Transform，不重新決定射擊結果；找不到表面時不留下浮空孔，但仍可播火花。網路表面以 NetworkObject 根 Transform 跟隨，支援位置、旋轉及非均勻縮放下法線還原；不追蹤子骨骼變形。孔是平面 Quad，不會沿牆角或曲面投影裁切，邊緣命中可能突出，適合目前平坦牆面用途。

火花在命中時的世界位置播放；孔跟隨表面，火花不跟玩家鏡頭移動。來源 Prefab 有兩個非循環 ParticleSystem，duration 10 秒，但只有 time=0 Burst，粒子壽命分別 1 與 0.5 秒。副本在最後發射排程後停止發射，存活粒子播完才銷毀，避免空等十秒；最大秒數與同時數量另作保險。不修改原 Prefab。不支援含 NetworkObject 的火花素材。

## Host／Client 驗收順序

1. 兩個獨立程序，以 Host 和 Client 各自射擊 Default 牆面。兩邊應看到同一位置、角度及款式，只有一次火花；空槍、未命中、換彈均不生成。
2. 把每玩家孔上限設成 3，各人射四個不同位置。各自第一孔消失，另一人的孔數不被擠掉。切 Attack／Support 後再射，仍沿用同一配額。
3. 高射速連射，觀察 `LocalWeaponImpacts` 子物件：每射手不超過孔與火花各自上限；停止射擊後火花清空，孔仍留存。
4. 在 Host 和 Client 各試兩個 Layer 遮罩的開／關組合；Hit Mask 敵人傷害保留，預設不生成孔或火花。驗證同時使用攻擊步槍與治療 SMG。
5. 移動／轉動允許的網路表面，孔跟隨；停用／移除表面後孔清除。對靜態牆確認兩邊都有孔，檢查角落突出與 Offset。
6. 晚加入只見加入之後的新效果；射手離線／Despawn、切關或回 SafeHouse 後，其容器消失，不殘留 MissingReference。重連後配額重新開始。

以上多人與實機畫面項目仍待手動驗收，EditMode 測試不取代此證據。
