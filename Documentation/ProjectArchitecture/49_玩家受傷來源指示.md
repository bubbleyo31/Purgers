## 已確認範圍與責任

使用者確認全新功能，採 2D 紅色短弧與世界來源位置的中空倒三角；預設淡色透牆，可切換直接隱藏。位置由權威受傷當下快照提供，不持續追蹤敵人。本次明確授權自動配置 Scene／Prefab。

DamageReceiverUtility → PlayerHealth → 原 RPC_ReceiveLocalDamage（State Authority → Input Authority）→ LocalDamageReceived → LocalPlayerDamageIndicator。沒有另一套傷害、生命、相機或網路物件。UI 不從血量差反推受擊。

- 原本有效 HP 傷害路徑不變。完全被 Modifier 吸收的結果仍為 FullyBlocked；IBlockedDamageFeedbackReceiver 只補回饋，PlayerHealth 再檢查有效生命週期、State Authority 與存活，不扣 HP、不呼叫 DamageApplied、不重跑 Modifier。
- DamageRequest 可提供 HasSourceWorldPosition／SourceWorldPosition，僅供來源快照，不更動傷害與歸屬。優先序：明確快照 → SourceNetworkObject Root → SourceObject Root → -HitDirection（只有方向，無 3D）→ 無提示。普通敵人的預設來源目前是根物件位置，並非自動推算槍口或頭部。
- ActiveAbilityPhysics 的 Explosion 使用 point - normalizedDirection * distance 作為爆心快照，保留原攻擊者歸屬。新增其他特殊來源時應由該來源明確提供位置，不由 HUD 猜測。
- 同一有效 NetworkObject 來源的新命中刷新一筆提示；沒有 NetworkObject 身份的事件分開處理。預設最多 4 筆，滿額取代最舊。
- 晚加入／重連不重播 LastDamage 欄位；死亡、Despawn、停用、換 PlayerObject 清空。只綁定本地 Input Authority；自動尋找只接受唯一有效本機 Runner，Multi Peer 使用明確 Runner／Camera 引用。

## 資產與設定入口

- 設定：`Assets/_Project_Assets/UI/BattleHUD/DamageIndicatorV1.asset`。
- 可重用 Prefab：`Assets/Prefabs/UI/DamageIndicators.prefab`。
- Scene：`Assets/Scenes/_Menu.unity` → `GameplayHUD Canvas/PlayerHUDCanvas/DamageIndicators`。
- Component：LocalPlayerDamageIndicator。Settings 指向共用設定資產；Runner 留空於一般單一 Session 自動綁定；World Camera 留空讀 Camera.main，手動指定時須為世界相機，不是 ViewModel 相機。
- DamageIndicatorSetup.Apply 僅新增本功能；需未有未儲存修改的 _Menu。重跑不覆蓋既有設定，不重排原 HUD。StageHUD 不重複掛載，避免兩份受傷 UI。
- 倒三角是世界座標投影至 HUD 的位置標記，面向畫面、固定螢幕尺寸；不是額外的世界 Mesh。Canvas 不加 GraphicRaycaster，圖形關閉 Raycast Target，不攔截遊戲輸入。

## V1 Inspector 配置

全部像素以 1920×1080 為基準，按相機 pixelHeight 與 Canvas scaleFactor 換算。可在 Play Mode 修改共享設定觀察，但修改 ScriptableObject 可能持久保存，調參前可複製設定資產作試驗。

| 項目 | 預設／有效範圍 | 效果與依賴 |
|---|---|---|
| Arc / Marker enabled | true | 各自開關；關閉 Marker 停止遮擋檢查 |
| Sprite | 空 | 空使用可調幾何；可替換任意 Sprite；2D 預設朝上 |
| Color | #FF5A4F，Alpha 1 | 圖形主色，Alpha 再乘不透明度與時間包絡 |
| Outline Color / Width | #251C1C / 1 px，寬 ≥ 0 | 0 關閉；自訂 Sprite 同樣可描邊 |
| Opacity | 0.9，0–1 | 可見時不透明度 |
| Fade In / Hold / Fade Out | 0.05 / 0.45 / 0.5 秒，各 ≥ 0 | 各層獨立設定；非縮放時間；遮擋變化不重啟計時 |
| Arc Radius | 100 px，≥ 1 | 距準星中心的弧線半徑；自訂圖形中心沿此半徑移動 |
| Arc Degrees / Thickness | 38°（1–180）/ 8 px（≥ 0.1） | 只影響內建漸尖短弧 |
| Arc Sprite Size / Rotation | 65×12 px / 0° | 只影響自訂 2D Sprite |
| Marker Size | 26×22 px，正值 | 固定畫面尺寸；不隨敵人距離縮小 |
| Triangle Line Width | 2.5 px，≥ 0.1 | 內建三角線寬；過大限制內縮以保留空心 |
| Marker Pivot / Offset | (0.5,0) / (0,0) px | 尖端對準來源；可調替換圖像的定位點與畫面偏移 |
| Occlusion Mode | FadeThroughWalls | 可切 HideBehindWalls；執行期間可即時切換 |

| Occlusion Interval | 0.05 秒，0.02–0.2 | 每個畫面內有效標記持續重查；不依賴相機是否移動，能偵測移動門牆 |

## 即時遮擋與效能

每幀更新投影／方向；物理遮擋採輪流排程。首次顯示／重新進入畫面先檢查，未檢查前不顯示 3D，避免一幀透出完整標記。HideBehindWalls 只改 Alpha，不停用排程，因此受擊後躲進牆後、探頭或門板移動都能重新切換。

每組最多 1 次起點 OverlapSphere（相機進入牆內的補救）與 1 次 Raycast，皆用 16 格固定緩衝，忽略 Trigger、受傷者及仍有效的來源 NetworkObject 階層 Collider。滿緩衝保守視為遮擋，避免穿牆漏判。只查受傷者所屬 PhysicsScene，不借用其他 Runner 場景。

預設 4 個標記 × 20 Hz，持續顯示時約最多 80 組／秒、160 次物理查詢／秒；每幀硬上限 2 組／4 次。新受擊／重新進入畫面會要求提早檢查，但仍受每幀上限約束。沒有標記、3D 關閉、只有方向或來源在畫面外不查詢。設定間隔不是任意低 FPS 下的絕對延遲保證；排程受遊戲幀率與標記上限影響。

圖形使用共用 UI 材質與可重用物件，不在查詢路徑配置陣列；未以本次小場景的結果宣稱大型關卡 GPU／CPU 性能驗收。

## 人工驗收

1. 正常開房進入關卡，讓敵人由不同方向造成傷害；2D 指向來源，3D 尖端對準來源快照。轉頭後方向更新；敵人移動不追蹤。
2. 同一提示未消失前走到牆後再探頭，應切 0.9 → 0.25 → 0.9；切換 HideBehindWalls 後應為 0.9 → 0 → 0.9。測試時可只在設定副本延長 Hold。
3. 相機靜止，讓門／牆移入與移出射線；仍需更新。檢查門 Collider 的 Layer 在 Obstruction Mask。
4. 來源在背後只留 2D；轉回且提示未過期時 3D 可出現，不重新計時。
5. 調整 Sprite、Color、Marker Size、Arc Radius 與兩層 Hold；結果應即時更新且不干擾原準心、技能與血量。
6. 護盾全吸收仍提示，HP 不變；死亡／重生清空舊提示。
7. 獨立 Host／Client 互看：只有受傷玩家顯示；Client 無法自行決定傷害，晚加入不播舊命中。
