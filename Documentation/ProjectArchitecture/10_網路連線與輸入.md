## 核心流程

```text
Unity 本機輸入
→ InputManager
→ NetInput
→ Fusion OnInput／Player Input Authority
→ Player 與各控制器在 FixedUpdateNetwork 消費
```

`NetInput` 是網路輸入快照，不應包含長期遊戲狀態。按住、按下沿與切換狀態若需要跨 Tick，應由對應 Controller 保存，例如跑步鎖定放在 `PlayerSprintLatchController`。

## 程式職責

| 程式 | 職責 | 主要連結 |
|---|---|---|
| `InputManager.cs` | 收集移動、視角、跳躍、射擊、瞄準、換彈、鈎索、蹲下／滑鏟等本機輸入，組成 `NetInput` 送入 Fusion | `NetInput`、`Player`、`PlayerMovement`、`PlayerGrapple`、`PlayerSlideController`、`AttackRifle` |
| `NetInput.cs` | 定義 Fusion 傳輸的輸入資料與 `InputButton` 按鈕位元 | 被玩家移動、武器、鈎索、職業能力讀取 |
| `Player.cs` | 取得該玩家 Tick 的 `NetInput`，協調玩家核心元件更新；也是 Player Prefab 的元件入口 | 幾乎所有 Player 子系統 |
| `GameLogic.cs` | 管理玩家加入、生成、死亡重生，並在 SafeHouse／Game 切場期間維持單一主實例、接管新場景出生設定與補回被卸載的 Player | `Player`、`PlayerHealth`、`PlayerProfession`、`ISceneLoadDone` |
| `MenuConnection.cs` | 判定 Quick Play／Host／Continue／Client Join，準備或限制本機存檔，再啟動 Fusion | `MenuConnectionBehaviour`、`GameSaveRuntimeContext` |
| `MenuConnectionBehaviour.cs` | 將 MenuConnection 接到 Fusion 連線生命週期／Behaviour | `MenuConnection` |
| `MenuSaveFlowController.cs` | Continue 選檔後重用主選單 ConnectionArgs，以 Host 身分開房 | `FusionMenuUIMain`、`JsonGameSaveRepository` |
| `MenuSaveLaunchPolicy.cs` | 以 Creating、Session 名稱與 Active Host Save 純計算連線意圖 | `MenuConnection` |
| `MenuSceneLaunchPolicy.cs` | 防止 PlayerPrefs 保留已從 MenuConfig 移除的舊 Scene，連線前解析成目前有效場景 | `MenuConnection`、`FusionMenuConfig` |
| `SafeHouseFlowController.cs` | 由 State Authority 驗證 Host 距離、處理玩家 Ready 切換、3 秒倒數並載入 Game | `SafeHouseHudController`、`GameLogic` |
| `MenuUIController.cs` | 選單 UI 操作與連線畫面控制 | Menu connection flow |

## 權威規則

- `InputManager` 只在本機採集，不直接改遠端玩家狀態。
- Player NetworkBehaviour 在 `Spawned()` 後才可讀寫 `[Networked]`。
- Client 的輸入是意圖；State Authority 才確定傷害、死亡、Enemy 生成等結果。
- Quick Play 與 Continue 的存檔只由 Host 本機寫入；Party Join 的 Client 使用 ReadOnly Context，不建立或覆蓋 Host 存檔。
- SafeHouse 的 E 只是本機請求；是否為 Host、是否在距離內、Ready 名單與切場均由 State Authority 再驗證。
- 新加入安全屋的玩家一律為未準備；離線玩家由 Ready 名單移除。Ready Check／Countdown 期間可切換自身狀態；倒數中取消會由 State Authority 立即回到 Ready Check。
- RPC 應有明確方向。Client 要求測試生成 Enemy 時，由 `EnemyPatrolAreaTestSpawner` 的 RPC 送到 State Authority，再呼叫 `Runner.Spawn`。

## 修改警戒

- 不要把新增按鍵直接散落到多個 `Update()`；能進 `NetInput` 的網路遊戲輸入應集中在 `InputManager`。
- 純本地 Debug 熱鍵可以留在測試元件，但正式 Build 要能停用。
- 不要在 `NetInput` 保存冷卻、生命或職業，這些不是輸入。
