## 設計定案

沿用 Tank Profession Runtime 與 IncomingDamageModifierBridge；三項強化是普通角色屬性，不新增技能槽或第二套傷害／耐力系統。

| 項目 | 未強化 | 各階最終加成／結果 |
|---|---|---|
| 防禦減傷 | 40% | +15／20／30／40／50 個百分點；最終 55／60／70／80／90% |
| 防禦耐力 | 100 | +100／200／300；上限 200／300／400 |
| 防禦冷卻 | 無減免 | 5／10／15／20／30% |
| 一般恢復等待 | 3 秒 | 冷卻強化後 2.85／2.7／2.55／2.4／2.1 秒 |
| 破防禁止防禦 | 5 秒 | 冷卻強化後 4.75／4.5／4.25／4／3.5 秒 |
| 恢復速度 | 最大值的 25%／秒 | 不受冷卻強化影響；上限 100／200／300／400 時每秒 25／50／75／100 |

- 每次實際阻擋量為 `min(進入此 Modifier 的傷害 × 減傷比例, 剩餘耐力)`；只消耗實際擋掉的耐力，餘傷繼續走既有傷害管線。
- 防禦中不恢復。一般輸入封鎖只禁止舉防，不暫停耐力恢復；死亡沿原中斷流程。正常結束防禦後開始一般等待，到期才逐 Tick 恢復；重新舉防取消等待，再次放開重新計時。
- 耐力歸零立即破防，禁止舉防。破防到期直接進入正常恢復，不回滿、不再加一般等待。從零補滿需 4 秒恢復時間。
- 破防期間持續按住防禦，到期後第一個恢復出正耐力的 Tick 自動舉防；舉防後停止恢復，可能再次快速破防。仍遵守既有攻擊、衝刺、鈎索及控制鎖。
- 冷卻強化僅在下一次建立一般等待／破防計時時取樣，不追溯縮短運行中的計時。
- 容量強化補上新增容量；例如 30/100 → 130/200。破防期間升階仍維持零耐力，不跳過破防。容量減少時只裁至新上限。
- 三項屬性只有實際持有已 Spawn 的電鋸 Guard Runtime 時符合候選及領取資格。每次升一階、滿階離池；換武器、倒地、死亡、換關保留，整輪失敗清空。沿用 Host 存檔及訪客 session-only 規則，不新增訪客跨房恢復。

## HUD 與技能施法條

使用者確認的配置：準心下方既有自己異常區，格檔在第一列，異常列依原順位接在下面；技能施法條維持既有中央偏下位置。這是本機／觀戰呈現，不新增世界血條上的格檔列。

- 格檔顯示真實耐力／上限；防禦、未滿、等待恢復、恢復中及破防時顯示。滿值且未防禦、非電鋸、死亡或來源失效時隱藏，異常區自動向上收合。
- 格檔金色、低耐力警示色、恢復色由共用設定調整。破防顯示空條與剩餘秒數；冷卻倒數不能當作耐力填量。
- 沿用 LocalPlayerHealthSlider 的本機／觀戰綁定。唯讀 TankGuardAbility 同步狀態與 TickTimer，不另起 UI 時鐘、不發送 RPC。
- 異常原圖示、顏色、期限與固定順位保留，異常本身仍沒有文字／秒數。格檔是另列資源資訊，不加入異常狀態 enum。
- 自己異常列維持寬 280、準心距離 80、圖示保留寬 24＋間距 5。格檔列寬度採 1.1 倍、即 308（不超出父層），實際量條由 251 加寬至 279；與異常條維持同一水平中心。文字由 12 調為 14，標籤高度按字級至少 1.5 倍向上取整且最低 20，預設為 21；標籤至量條 6、量條高由 7 調為 8、至異常列間距 8。其餘異常沿原 24／6／4，施法條不移位。
- 可見技能條的實際 Graphic 範圍由 LocalPlayerBattleAbilityHUD 提供唯讀根節點，生命 HUD 在共同 anchor 座標量測；若格檔＋異常整組碰到施法名稱，整組往上讓出 8 單位。現行 1080 配置四列時頂端從 80 調為 57，三列以下維持 80；技能條隱藏後恢復原位，不改其計時或座標。

## 責任與保存相容

`PlayerGrowthState` 保留舊九項 Ranks 與六項 Passives 的配置；enum 16～18 是三項防禦屬性，新增 DefenseRanks 保存各自三個 bit。不得重新排列既有 enum。`GameLogic` 在原領獎交易提交階級後，呼叫原 Guard 更新容量；Host 的 CurrentStamina、AppliedMaximumStamina、Phase、兩個 Timer 供複製及 HUD 讀取。Input Authority 仍只提供意圖與既有預測，真正傷害／容量更新由 State Authority 決定。

存檔 schema v5 新增 PlayerRunProgressionData.DefenseGrowthRanks；v1～v4 未含此欄位時自然為零，原等級、待領獎勵、舊成長與被動不改。改動 NetworkStruct 與 Guard Networked 配置後，Host／Client 必須使用同一版程式及 Fusion weaving。
