相關文件：[90 敵人核心](90_敵人核心感知巡邏與追逐.md)、[91 敵人攻擊](91_敵人攻擊表現與生成.md)、[30 鈎索](30_鈎索系統.md)、[驗證](Validation/SuicideEnemy/README.md)。

## 使用者定案

- 地面巡邏、發現後追逐，定位為數量型敵人；沿用 EnemyActor、感知、地面導航、CombatDecision／ActionGate／MovementOwnership 與 Encounter。數量仍由生成區與全場預算設定。
- 已發現目標進入攻擊距離：預備→本體拋物線撲擊→前段有限修正→固定落點→抵達／時間到引爆。落點以起撲位置的最大水平半徑限制，不追上天空、不掉頭、不延長期限。目標死亡或失聯保留最後有效落點。
- 未主動發現而進入攻擊範圍、過快接近或貼身：原地引爆。預設零延遲，預留 Inspector 延遲。近身感知不受扇形限制，牆壁仍阻擋；以相鄰 Tick 相對位置線段防止高速穿越漏判。
- 玩家任何有效正傷害（槍、近戰、範圍、持續傷害）立即引爆，不看剩餘血量；傷害被拒絕／無敵不觸發。死亡結果保留玩家攻擊者與真正命中量，不偽造額外傷害跳字；沿用正常經驗流程。
- 自主引爆不帶玩家攻擊者、不給經驗；同一隻只死亡／爆炸一次。環境致死也爆炸，但無有效玩家擊殺者不給經驗。爆炸只對玩家結算，不連鎖炸其他敵人。
- 玩家射爆仍會傷害玩家，施加相同 Debuff。
- 爆炸當下固定自身中心；三維球形，距離量至玩家 KCC 膠囊最近點，實體牆／樓板遮擋；玩家與敵人不當成遮蔽物，包含位於 Default Layer 的執行期 KCC 膠囊。
- 傷害、緩速幅度、緩速秒數與鈎索封鎖秒數皆按距離線性衰減。中心減速預設 50%；外緣允許少於一秒，範圍外零效果。
- 命中立即強制斷鈎，不產生額外釋放加速，保留既有動態速度；封鎖期間不能再次出鈎。只減少地面走路／奔跑位移，不縮放空中慣性、滑鏟或技能 Dash。
- 各次緩速獨立到期、有效期間取最強，不相加；鈎索封鎖取最晚到期。封鎖結束只移除本來源，不移除其他來源限制。
- 既有鈎索不可用 UI 同時讀取能量與 ActionGate；能量圈保持真實數值，不扣空能量模擬封鎖。
- 準心遮擋圖檔只預留 Sprite 欄位，本階段不製作視覺遮擋。

## 架構與權威

`EnemyCombatOption` 增加預設關閉的近身 Context 與失去目標繼續執行接口。只有 `EnemyCombatDecisionController` 啟動攻擊及配置 Ability 鎖；其他敵人的行為保持原契約。外部位移在預備階段取消攻擊，已離地時在當前位置結束爆炸；時間凍結沿用既有 PauseSimulationTick，凍結期間不推進飛行期限。

`TestDamageReceiver` 通過權威／正傷害／無敵檢查後詢問可選 `IEnemyFatalHitPolicy`；自爆怪將當次有效命中轉成正式死亡。Health／DeathLifecycle／GameLogic 仍是唯一生命、死亡與經驗擁有者。

`PlayerActionGate` partial 保存權威鈎索 TickTimer，Host 保留仍有效的各次緩速並同步最強倍率及該倍率期限。Input Authority 與 Proxy 讀同步結果；Client 不能提交 Debuff。玩家死亡／Despawn 清理效果，不保存到存檔，重生重設。Host migration 尚不支援私有緩速清單重建。

`PlayerMovement` 在既有 KCC PrepareData 追加本 Tick 地面 Kinematic 位移修正，不反覆縮小持久速度。`PlayerGrapple` 的正式出鈎入口與 CanUseGrapple 共用 ActionGate。VFX 由 State Authority RPC 發佈一次位置／半徑，各端本機播放，與敵人分離並定時清理；晚加入不補播過去爆炸。

落點探測只採用實體世界地板，忽略玩家／敵人膠囊，避免落點變成站在玩家頭上。

原型只對正式傷害結果 Accepted 的玩家施加 Debuff；完全免疫／完全阻擋不施加。傷害設為 0 時亦不施加 Debuff。

## 手動接線與驗收

1. 打開 Enemy_Suicide Prefab，確認 Root scale=1、看門菇約 2.1m；Capsule／Hitbox／導航依文末設定，只有一顆模型 Animator，無 NavMeshAgent。
2. 核對 World Mask、Perception Occlusion Mask、兩個 Navigator Obstacle Mask 均只包含地板／牆。移動導航與攻擊落點 Agent Type 必須與地圖預烘焙資料一致。
3. 在既有開發生成器或正式 Enemy Spawn Zone 手動加入 Enemy_Suicide；地面生成沿用 Runtime Chunk Patrol Area 綁定。未自動修改候選表、Scene 或 MapChunk。
4. 進 Play Mode，先驗證巡邏、正面發現追逐；從側後方直接進入攻擊範圍應原地引爆。高速穿過觸發圈也應引爆，隔牆不觸發。
5. 在約4m等待起撲：早期小幅橫移可修正，後段轉向可閃避；目標跑遠、死亡或離線不可無限追蹤。撞牆在撞點爆炸。
6. 使用低傷害子彈、近戰、範圍技、持續傷害各一次，均應立即引爆並按既有隊伍規則領經驗。自主爆炸不領。自然 GameLogic／Active Stage 經驗顯示須另驗收。
7. 靠近／中距／外緣比較傷害、減速與封鎖秒數；鈎索使用中被炸應立刻斷開，能量保持、禁用標記亮起，外緣可很快恢復。
8. 連續受到強短／弱長效果：先強後弱，最後完全恢復；不得相加成無限禁錮。另有封鎖來源時不得提前解除。
9. Host／Client 分別受擊，晚加入／重連觀察剩餘狀態。大量爆炸的粒子／音訊／CPU 成本須以目標硬體 Profile，單隻測試不等於大量效能合格。

## 動畫交付

建議5支：Idle（循環）、Walk（循環）、Run（循環）、PounceStart（單次）、PounceAir（短循環／保持）；最低3支可共用移動並合併撲擊。無需受傷、倒地死亡、落地收招或原地自爆動畫。

全部使用原地動畫，不以 Root Motion 再加前進／跳高。起撲提供原始長度、FPS、倍率與離地幀；空中段可適應飛行期限，有限轉向時姿態仍需成立。任何階段均可立即中斷爆炸，不等待淡出。2026-10-16 已提供看門菇模型與四支動畫，接入唯一 EnemyPresentationAnimatorDriver，空中沿用 PounceStart 尾幀；詳見下節。

### 資產成本與限制

沿用 22 個 SkinnedMeshRenderer、22 個材質槽、2 種材質、6,804 個 Unity 匯入頂點、10,990 個三角形、50 個使用中的骨骼；8 張不同的 1024×1024 貼圖。沒有重建模型、拓樸或降低面數。原始 FBX 匯入已有「柱体.009 自交面被捨棄」警告，本次未改動來源修面。

Idle 腳底已貼近 Root 地面；原始跑步／預備動作存在部分腳掌穿地，未改寫作者的腿部姿勢。固定 Hitbox 不會逐肢體精確貼合每個姿勢。這些視覺與命中範圍需實際遊玩驗收；數量型部署仍需目標硬體 Profile，單隻動畫通過不代表大量效能通過。

程式入口：`EnemySuicideModelSetup.InstallConfirmedModel` 僅首次替換；已有 Animator 時拒絕重複套用。Inspector 重建按鈕只更新衍生 Clip，不重置 Prefab 人工數值。驗證詳見 [模型替換驗證](Validation/SuicideEnemy/Model_20261016.md)。
