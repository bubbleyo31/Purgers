# 玩家核心、移動與狀態架構

> 最後核對：2026-09-15  
> 相關文件：`10_網路連線與輸入.md`、`30_鈎索系統.md`、`40_職業與特殊能力.md`、`41_玩家能力Loadout.md`

## 資料流

```text
NetInput
→ Player
→ PlayerMovement（KCC 基礎移動）
   ├─ PlayerSprintLatchController（跑步鎖與加速累積）
   ├─ PlayerSlideController（蹲下、滑鏟、鏟跳）
   ├─ PlayerGrapple（拉動與釋放動能）
   ├─ PlayerStateMachine（語意狀態）
   └─ IPlayerMovementInputModifier（職業 Runtime 或獨立 Ability Runtime 修改輸入）
```

## 程式職責

| 程式 | 職責 | 主要連結 |
|---|---|---|
| `Player.cs` | Player Prefab 組裝根、網路輸入與各控制器協調 | 所有玩家核心、職業 Runtime 與 Ability Runtime |
| `PlayerMovement.cs` | Advanced KCC 移動、地面／空中速度、跳躍、二段跳、重力、鈎索後 Momentum 與速度輸出 | `KCC`、`PlayerStateMachine`、`PlayerSlideController`、`PlayerSprintLatchController` |
| `PlayerStateMachine.cs` | 定義並同步 `PlayerMovementState`、空中行動等玩家移動語意 | Movement、Slide、Grapple、能力與動畫 |
| `PlayerSprintLatchController.cs` | Shift 按下後維持跑步直到停止；管理約 2 秒跑步速度累積及被蹲下／滑鏟清除 | `PlayerMovement`、`PlayerSlideController`、State Machine |
| `PlayerSlideController.cs` | Left Control 蹲下／滑鏟；速度門檻、鈎索後落地寬鬆觸發、滑鏟重置跑步動能、鏟跳與鏟跳後解除蹲下 | Movement、Grapple、Sprint、State Machine |
| `IPlayerMovementInputModifier.cs` | 職業 Runtime 與獨立 Ability Runtime 對移動輸入的統一修改介面 | `PlayerProfessionRuntimeManager`、`PlayerAbilityRuntimeManager`、如 `SupportAerialAbility`、`TankGuardAbility` |
| `PlayerLocalView.cs` | 只替 Input Authority 啟用相機、第一人稱模型、移動效果與本地視覺 | Camera、ViewModel、Movement Effects |
| `PlayerIncomingDamageModifierBridge.cs` | 玩家受傷 Modifier 的集中橋接，不屬於移動但位於 Player 核心組裝 | `IPlayerIncomingDamageModifier`、Damage System、Tank Guard |
| `IPlayerIncomingDamageModifier.cs` | 定義玩家職業能力修改進入傷害的介面 | Bridge、Tank Guard |

## 已確定的移動規則

- 跑步：按下 Shift 後鎖定跑步，直到玩家停止；不是必須持續按住，也不是再次按下切換關閉。
- 跑步速度：從基礎速度逐漸提升，約 2 秒到設定的跑步倍率。
- 蹲下：在跑步動能累積期間按下會清除此輪累積。
- 滑鏟：開始瞬間重置跑步累積，避免連續滑鏟永久維持最高動能。
- 鈎索後落地滑鏟：只要本輪使用過鈎索且玩家觸地前已蹲下，可用較寬鬆門檻進滑鏟。
- 鏟跳：成功時使用 `PlayerMovement` 內獨立可調的鏟跳數值，之後解除蹲下狀態。
- 鈎索後 Momentum：保留釋放前速度並受重力／衰退影響，但主動移動輸入優先於 Momentum。
- 主動使用鈎索後可恢復二段跳；空中使用二段跳仍算 GrappleAirborne，地面一般二段跳不算。

## 控制權與常見錯誤

- `PlayerMovement` 是唯一主要 KCC 寫入者；其他能力應透過公開方法、Dynamic Velocity 或 Modifier 合作，不應直接改 `transform.position`。
- Support 拉玩家使用 `SupportGrapplePlayerPullReceiver` 與 KCC，不可搬用 Enemy Rigidbody Receiver。
- 瞄準、特殊能力、Tank 防禦若要封鎖 WASD，應實作 `IPlayerMovementInputModifier`，不要永久清空原速度。
- Presentation 不應回寫 Movement State。

## 表現連結

- `FirstPersonMovementEffects`：一般高速、落地等視覺。
- `FirstPersonSlideReadySpeedLines`：獨立的可滑鏟速度線與門檻。
- `FirstPersonMovementAudioController`：走路、跑步、跳躍、滑鏟、鈎索風聲。
- `LocalPlayerSpeedSlider`：從 `PlayerMovement` 讀速度並封頂顯示。
