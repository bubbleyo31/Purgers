## 待釐清，暫不由後續實作者自行猜測

1. 非整格血量按比例裁切原輪廓，禁止壓縮造成血格斜率變動；最大血量非 20 倍數時以 `Ceil` 取格數。
2. 鈎索歸零時「右上到左上」線段的實際角度、是否穿越圓心，需美術圖確認，不能單靠文字做成禁止符號。
3. 中央 Q 與右下 Q 分別表示鈎索使用與鈎索命中能力；兩者共用按鍵時，實際命中觸發流程與重綁後文字應由既有輸入／能力路由決定，不由 HUD 另訂優先序。
4. 已決定：獎勵待選提示閃爍；按住 ALT 時依本圖中央橫排展開選窗，三項用左／中／右鍵，兩項用左／右鍵；選擇鍵優先於射擊／瞄準，WASD、視角與其他操作不鎖，世界時間繼續。ALT 長按門檻及放開後選窗關閉的精確時序，待 UI Runtime 實測決定。
5. 已決定：同次擊殺的超額經驗保留；未選獎勵期間，權威端拒收該玩家後續擊殺經驗。HUD 停在滿格僅為表現，不得自行更改權威數值。
6. 左上關卡倒數不足一分鐘時變紅，恰好 `01:00`、Unlimited、無計時的顯示規則；紅色是否需脈動或音效尚未指定。

## 武器 HUD 清理後的正式接線

```text
PlayerHUDController [LocalPlayerWeaponHUD]
└─ WeaponHUDRoot
   ├─ WeaponIconImage
   ├─ CurrentAmmoText
   ├─ MagazineCapacityText
   ├─ ReloadReminder
   └─ ReloadProgressRoot [Image：暗底]
      └─ Fill [Image.Type.Simple：亮色]
```

- `currentValueText`／`secondaryValueText` 分別連到兩個 TMP；`weaponValueText` 只為舊 Scene 相容，可留空，不需重建已刪的舊文字物件。
- `weaponIconImage`、`weaponHUDVisualRoot` 與 `fallbackWeaponIcon` 沿用目前物件／素材。局部修復工具 `BattleHudReferenceLayout.RepairWeaponHudReferences` 只接現有階層、配置量條並存檔，不重建舊物件或重排版。
- `reloadProgressRoot` 與 `reloadProgressFill` 分別指定暗底 Root 與其直接子物件 Fill。Fill 的左下錨為 `(0,0)`，右上錨為 `(p,1)`、offset 為 0，唯一寬度更新者是 `LocalPlayerWeaponHUD.SetReloadProgress`。不要再加 Slider、LayoutGroup 或動畫同時改 Fill 寬度，也不要以 fillAmount 當此元件的進度。
- `p = Clamp01(1 − ReloadRemainingSeconds / ReloadDurationSeconds)`，仍由 Attack／Support 的已 Spawned 武器資料來源提供。暗色剩餘區逐漸縮小、亮色由左至右增加；不另外倒數、不改換彈的權威時序。
- 彈數沒有變化時量條仍更新。低彈 `R` 提醒與正在換彈的量條各自判斷，剩餘彈數高於提醒門檻也能顯示換彈。
- 完成、取消、死亡／職業切換／來源失效時，量條隱藏且寬度歸零。

- 新款容量 TMP 的分隔符會去掉外側空白，兩個 TMP 禁止自動換行，避免舊格式 ` / ` 把 `/25` 拆成兩行；舊單一 TMP 相容格式仍保留。
