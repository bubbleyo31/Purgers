# 一般與大型敵人百分比分格血條

最後核對日期：2026-10-14（本輪局部核對）  
核對來源：Assets/Scripts/UI/Enemies、EnemyHealthBarSetup、EnemyHealthBarTests、EnemyHealthBarVisibilityTests。  
相關文件：[101 隊友顯示](101_隊友辨識與穿牆顯示.md)、[60 生命](60_傷害生命死亡與回饋.md)、[驗證紀錄](Validation/EnemyHealthBars/README.md)。

## 已確認範圍

- 使用者確認為全新功能；一般與大型一般敵人顯示分格血條，固定螢幕大小並跟隨位置。
- 固定格數代表生命百分比，允許部分填格；不採隊友每格固定 HP／累積整格餘額。
- 不穿牆、不顯示畫面外箭頭。整隻離開畫面、完全遮擋、死亡、Despawn 或來源失效就隱藏。
- 大型一般敵人頭頂錨點出框但身體仍在畫面內時，使用該敵人可見身體區域上緣的畫面內備用位置；回到正常位置有緩衝。
- Boss 血條排除本次範圍。不在 Boss 上掛 EnemyHealthBarTarget；若從共用 Prefab 繼承，Display Mode 必須設 Hidden。
- 滿血且尚未變動、也沒有可見異常時隱藏。有可見異常時的顯示覆蓋規則見 [105](105_異常狀態圖示與持續量條.md)。生命數值（含最大生命）改變後顯示，連續 10 秒沒有再變動則隱藏；扣血、回血皆重新計時，回滿血也先保留本次 10 秒顯示窗。零傷害／被拒絕的傷害不續期。
- 沒有新增敵人名稱、護盾、殘血變色、瞄準限定或穿牆提示。
- 10 格、118×9、米白等為可調起始值，不是不可修改的設計定案。

## 資料與責任

1. TestDamageReceiver 仍是唯一生命真相；Host 修改原 CurrentHealth，Client 讀取原同步值。沒有新增 HP、Networked 欄位或 RPC，不依賴只在 Authority 觸發的 HealthChanged 事件。
2. EnemyHealthBarTarget 掛同一個敵人 NetworkObject Root，是無 Networked 欄位的呈現 NetworkBehaviour。在 Spawned 只註冊，首次 Render 才讀其他生命元件，Despawn／Disable 清除快照。設定來源為同 Root TestDamageReceiver。EnemyHealthBarActivity 追蹤目前／最大生命值與最後本機觀察變化時間；IsReadyFor 額外檢查顯示期限，逾時候選不進行遮擋射線。
3. 本機註冊清單只保存呈現引用；HUD 嚴格限制同 Runner、Object.IsValid、完成 Spawned 且有 Render 快照。沒有 process-global Gameplay 狀態。
4. LocalEnemyHealthBarHUD 使用 Screen Space Canvas，讀世界相機投影與 Runner.GetPhysicsScene；每端視角與遮擋獨立，UI 不裁定命中或傷害。
5. EnemyHealthBarVisibility 使用人工主要身體盒，將盒邊裁切到相機近／遠平面再投影。對投影可見部分作 3×3 採樣，射線與本機身體盒相交後，查詢前方 Collider。忽略 Trigger、自身與本機玩家；32 hit 緩衝滿時保守隱藏。
6. EnemyHealthBarRules 處理比例、部分格、視口內位置及切換緩衝；EnemyHealthBarGraphic 每條只產生一個 Graphic，固定底格與比例填色。LocalHealthSegmentView 保留原生命呈現；隊友／本機玩家 HUD 已接共用異常圖示量條（105）。
7. HUD 重用顯示物件，較近候選優先；每幀可見數及遮擋候選有上限，未重查者隱藏而非保留舊透牆狀態。切換 Runner、失去相機、換場與 Disable 清理。

## 生命變化顯示期限（2026-10-14 後續修訂）

- `EnemyHealthBarActivity.VisibleSeconds = 10`，本次為固定規則，不新增 Inspector 設定或修改已接線 Prefab。
- 以 `Time.unscaledTimeAsDouble` 計本機實際秒數，從最後一次觀察到生命數值變化起算；剛好滿 10 秒就隱藏。不因鏡頭、遮擋、位置、HUD 開關而重新計時。
- Target 在 Render 持續觀察有效生命快照，即使血條正隱藏仍可因下一次生命變化重新出現；死亡仍立即隱藏。
- Spawn／Despawn 重設呈現歷史，避免物件池沿用上一隻敵人的期限。暫停 HUD／Target 顯示本身不重設已記錄期限。
- 第一次有效快照已是殘血（例如晚加入／重連）時，提供新的本機 10 秒觀察窗；初次滿血仍隱藏。各端不追補不可得的歷史受傷時間，也不新增 Networked 時戳或 RPC。
- 使用完整生命數值比較，極小有效變化及目前／最大生命同幅改變都算變化。兩次 Render 之間若先扣再補且最終數值完全相同，快照層無法辨識中間事件，不會額外延長。

本輪接線清單：

每個敵人 Root 已加入 EnemyHealthBarTarget、EnemyHealthBarAnchor 並重新 Bake NetworkObject。樹怪取頭、軀幹與雙腿；水母取主要球形身體，排除伸展手臂、觸手、護盾和特效。離線骨架 BakeMesh 比例不可靠，因此接線工具使用已匯入 Renderer 的世界 bounds 轉換為 Root 本機盒，並以合理尺寸測試及正式 Prefab Play Mode 檢查。實際數值見 [接線報告](Validation/EnemyHealthBars/Wiring/wiring.txt)。錨點目前是 Root 下固定局部位置；大幅骨骼位移仍需以動畫觀感校準。

**Tools > Purgers > UI > Wire Approved Enemy Health Bars** 可補齊核准清單中的缺失元件與 HUD，需開啟乾淨的 _Menu。已有 Target 或 HUD 時保留設定，重跑不改寫人工值；不修改 Boss 或共用基底。以下步驟供後續新增敵人與人工微調使用，現有 9 個敵人不需重接。

1. 若獨立資產缺少，使用 **Tools > Purgers > UI > Create Enemy Health Bar Assets**。只建立缺少項目，不覆寫既有值，不保存正式場景。
2. 把 EnemyHealthBarDisplay 放到 `_Menu/GameplayHUD Canvas/PlayerHUDCanvas` 既有 Screen Space Canvas 下，與 TeammateDisplay 同層；根 RectTransform 拉滿、offset 0、Scale 1。不放入 Mask、不使用 World Space Canvas；Game／SafeHouse 不再重複放一份。
3. Local Enemy Health Bar HUD 的 Settings 指向 EnemyHealthBarV1。單 Runner 可讓 Runner／World Camera 留空；Multi Peer 必須兩者皆明確指定。使用遊戲世界相機，不是第一人稱手部相機。
4. 在要顯示的**一般敵人 Prefab 根節點**加入 EnemyHealthBarTarget，根節點需已存在 TestDamageReceiver／NetworkObject。Normal 為一般；大型一般敵人選 Large。Boss 不配置，繼承者選 Hidden。
5. Head Anchor 可人工建立並指定在頭頂；不填則使用 Body Center + 半高。Body Center／Size 是相對此元件 Transform 的公尺尺寸；用 Scene 選取 Gizmo 校準，貼合主要不透明身體，不納入武器／翅膀／觸手／特效。此盒只供顯示，不新增 Collider。
6. Obstruction Mask 必須包含牆壁與地形實體 Collider 的 Layer。Trigger 不會遮擋；只有 Renderer、沒有 Collider 的牆無法阻擋這項物理可見性查詢。
7. 人工保存指定 Scene／Prefab。新增呈現 NetworkBehaviour 後重新烘焙／匯入 Network Prefab，Host／Client 必須使用相同版本與相同設定資產；不需要新增存檔欄位。

## Inspector 調整手冊

| 入口 | 起始值／範圍 | 作用及相依關係 |
|---|---|---|
| Settings > Cell Count | 10；1～40 | 每格 = 最大 HP / 格數；每格填充 = Clamp01(HP/maxHP × 格數 − 格索引) |
| Bar Size | 118×9；最小 20×3 | 1080 高度參考像素。按相機視口高度縮放；同解析度遠近／不同最大生命皆同寬 |
| Gap | 2；>=0 | 格間距；最多佔每格步距 40%，不會擠成負格寬 |
| Health / Empty Color | 米白／深灰藍 | 填滿與容量底格；無低生命自動變色 |
| Padding | 8；>=0 | 血條底部與錨點／可見身體上緣距離，參考像素 |
| Edge Inset | 16；>=0 | 血條外緣距視口邊界；一般敵人放不下即隱藏，大型才可用備用位置 |
| Hysteresis | 12；>=0 | 大型敵人返回正常錨點前需多深入的距離，參考像素 |
| Follow Speed | 18；>=0 | 指數位置平滑，1/秒；0 立即跟隨。重新出現直接放定位點，遮擋隱藏與 HP 無延遲 |
| Obstruction Mask | Everything | 包含所有牆壁地形。0 會忽略全部遮擋，不符合本功能的不穿牆要求 |
| Max Distance | 0；>=0 公尺 | 0 不額外限制；大於 0 以相機到身體盒中心距離判斷 |
| Max Visible Bars | 32；1～128 | 每 HUD 同時顯示上限，較近優先；較遠可能因預算隱藏 |
| Max Visibility Checks | 64；1～256 | 每幀畫面內候選檢查上限，每候選最多 9 射線，取樣受遮擋可提前排除 |
| Target > Display Mode | Normal | Normal／Large／Hidden；與敵人體型或血量值無自動推論關係 |
| Head Anchor | 空 | 空時取主要身體盒上緣；指定時隨該 Transform |
| Body Center / Size | (0,1,0)／(1,2,1) | 本機公尺，各 Size 軸至少 .01；需按正式模型人工校準 |

範例：10 格、HP 76/100 或 7600/10000 都是 7 格全滿、第 8 格填 60%；HP 0.1/100 仍顯示首格 1% 寬，死亡時整條隱藏。格數改 8 則每格 12.5%，總寬不變。

Settings 值可在 Play Mode 調整觀察；要保留請依 Unity 資產儲存規則處理，勿把測試場景設定當作正式 Prefab。多人本機 UI 設定不走 RPC；各端一致性依同版資產。

## 驗收與限制

- 一般敵人初始滿血隱藏→少量傷害顯示→76%→無變化 10 秒隱藏→再受傷重現→死亡立即隱藏；持續扣血或回血延長期限，底格總寬不變。
- 遠近、不同最大生命、1080／其他解析度、超寬或相機分割視口確認血條尺寸與邊界。
- 大型敵人遠處頭頂正常；貼近腳邊頭出框而身體仍在畫面時保留備用血條。整隻離開畫面／背後不保留任何 UI。
- 完整牆、半牆、薄柱、拐角、上下遮擋、Trigger、不同 Layer；全遮擋當幀隱藏，移開恢復。
- 多人各自視角、晚加入、重連、死亡／Despawn、場景切換、停用／重啟 HUD；同 Runner 不混入其他 Peer 引用。
- 人工身體盒與九點採樣是有限近似，並非逐像素遮擋。極窄縫可能保守隱藏；盒子超出真實模型或牆壁沒有 Collider 可能錯估，必須以正式模型校準。骨骼大幅位移需人工錨點／合適盒子，不能納入武器或特效動態 Bounds。
- 多隻血條目前不作全場排版避讓，密集重疊仍需正式場景觀感驗收。預算起始值不代表已完成效能量測。
- 先前受控 Host／Client 使用簡單盒形敵人；本輪另完成 9 個正式 Prefab 的隔離 Single 生成、血量與清理驗證，仍不能代替自然關卡操作、獨立程序多人或 Build 驗收。具體已測範圍見驗證紀錄。
