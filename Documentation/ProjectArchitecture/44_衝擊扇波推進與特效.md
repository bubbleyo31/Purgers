## 1. 已確認行為與責任

使用者看過圖解後確認：**固定大小的直立弧形波牆，整片向前平移；上下邊緣同寬，不往頂端收攏。**
Radius 控制波牆局部弧半徑；Travel Distance 控制整片平移距離；Wave Height 獨立控制高度。
這取代同日較早的「球殼隨距離擴張」版本，不再使用三維球距作正式命中範圍。

前搖結束、正式 Activate 當下才讀 KCC TargetPosition、LookPitch 與 TransformRotation（Yaw）。
整片波牆跟著瞄準俯仰傾斜；出手角度使用完整 Quaternion，朝正上／正下仍保留玩家左右軸，不使用 LateUpdate 的相機呈現 Transform。
Origin Offset 是瞄準座標的 XYZ 公尺偏移：X 右、Y 上、Z 前；期望出發點 = KCC TargetPosition + 出手旋轉 × Origin Offset。
Wave Height 沿波牆局部上方延伸；空中不找地板、不吸附地面。出手後原點與旋轉固定，玩家移動、落地或轉向不會拖動／轉彎。

出發點沿用 ActiveAbilityPhysics.TryResolveShotOrigin：從玩家膠囊中心到期望出發點查 Obstruction Mask，以零半徑射線避免偏移跨薄牆；忽略自身與其他玩家。
遇障礙就縮回其前方 0.002m；安全錨點已埋入障礙則取消本次出手並沿用既有冷卻結束流程。
此解析只處理出發點，並非整片大型波牆的網格裁切；沒有重力或地形跟隨。

PlayerShockwaveAbility 仍是唯一 State Authority Owner。施放時快照原點、方向、完整 WaveRotation、位移上限、半徑、半角、速度、厚度及高度。
每 Tick 對固定波牆的完整平移路徑做連續掃掠，敵人每波最多命中一次；逐目標遮擋、DamageReceiverUtility、EnemyStateController 擊退／撞牆傷害／暈眩保持。
候選使用包覆整段路徑的保守 OverlapSphere，再以每個符合 Hit Mask 的敵人受擊 Collider 中心篩選精確範圍；可見網格不決定傷害。
遮擋從已解析的發射原點到候選 Collider 中心檢查，使 XYZ 偏移也影響遮擋來源；並非逐網格裁切。敵人擊退仍由 EnemyStateController 使用世界水平移動，不因波牆傾斜新增垂直拋飛。

Input Authority 沿用 NetInput.Ability1；Client 不能直接決定施放或傷害。
Render 只讀同一施放序號的同步 WaveFront 並插值，交給 PlayerShockwaveVisual。
本機 VFX 沒有獨立時計、Collider、Rigidbody 或 NetworkObject；固定網格只於尺寸改變時重建，之後以 Transform 平移。
晚加入從當前位移繼續；已結束不補播。死亡、不可用、卸裝／Despawn 及完成位移時清理。
冷卻仍於施放後開始；波未結束時拒絕新施放，避免零冷卻覆寫去重名單。

## 2. 精確幾何與距離定義

所有尺寸以公尺計算、不隨 Prefab Scale 放大；下列 x/y/z 均為出手時瞄準座標。世界點 = WaveOrigin + WaveRotation × 局部點。

- R = Max(0.1, Radius)，局部外弧半徑。
- w = Clamp(Wave Thickness, 0.05, R)，內弧半徑 r = R − w。
- α = Clamp(Half Angle Degrees, 0, 180)，總角為 2α；α=0 不顯示也不命中。
- H = Max(0.1, Wave Height)，底部 y=0，頂部 y=H。
- D = Max(0.1, Travel Distance)，整片波牆的平移上限。
- 弧心偏移 c = −r cosα（cosα ≥ 0），否則 c = −R cosα。
- 施放座標中的表面點：(ρ sinθ, y, d + c + ρ cosθ)，ρ 在 [r,R]、θ 在 [−α,α]。
- 每 Tick：d = Min(D, d + Wave Speed × Runner.DeltaTime)，完成最後一段傷害掃掠後結束。生命週期約 D / speed，受 Tick 量化影響。

弧心偏移把波牆最後緣放在施放平面，所以初始就在玩家前方，沒有一半埋在施放者身後。
**Travel Distance 是整片位移，不是玩家到最前緣的總射程。** 最遠前緣為 D + c + R。
半角 ≤90° 時，局部總寬度為 2R sinα；半角 ≥90° 時為 2R。整片弧線的高度相同。

本輪最後讀取 R=8、α=60°、w=1：局部寬度約13.86m、自身前後深度4.5m；D=20 時最前緣到24.5m。
這是保留人工 Radius=8 所產生的固定尺寸，不會自動改成圖解的示意 R=4。
波牆一開始已具完整尺寸，弧後方的中空區域不會因施放而整區受傷；與先前從零擴張的球殼不同。

連續掃掠把目標反向平移成線段，檢查端點及內外圓／角度切面的交點；高速跨過靜止敵人不需增加離散採樣。
這不是移動敵人歷史軌跡的碰撞回溯，也沒有新增 Lag Compensation。
有限分段的可見網格是解析弧面的近似；沒有依牆壁為每個三角形重建裁切。

### 手動調整順序

1. 非 Play Mode 開啟技能 Prefab，核對人工 Radius=8、Wave Height=5、Wave Speed=60。
2. Origin Offset 設定發射點；例如 (0,1,0.5) 表示瞄準座標向上1m、向前0.5m，抬頭低頭時兩軸一起旋轉。改 Radius 看寬度；改 Travel Distance 看終點；改 Wave Height 看上下尺寸。Gizmo 同時顯示起始／終止波牆與整片位移箭頭。
3. 重現已確認圖解可自行設 Radius=4、Travel Distance=10、Wave Height=3、Half Angle=60、Thickness=1；這是示意起點，不是本次自動套用的平衡值。
4. Travel Distance 從10改成20、保持 Radius=4，寬度應不變；速度20時生命週期從約0.5秒變1秒。只改高度3→6，水平輪廓不變。
5. 前搖途中改變瞄準方向，確認沿出手瞬間方向發射；出手後再轉向不改變波牆。儲存自己的調整後重新施放。施放中的快照不被 Inspector 改值影響，下次才套用。
6. 同版本重建多人兩端；新增 WaveRadius、WaveHeight、WaveRotation 網路欄位，WaveRange 現為平移上限，不能混用舊版 Client。

顏色與細節仍在 Assets/Resources/Presentation/Shockwave/ThickWave.mat 調整。
視覺 Prefab 的 arcSegments（8～96）、elevationSegments（8～48）只影響平滑與成本，不改正式命中規則。
工具 Tools/Player Ability/衝擊扇波/輸出隔離預覽 以 R=4、高3、位移5／10／18m 輸出 Temp/ShockwaveVfxPreview，只有美術預覽意義。

## 5. 驗收界線

- Radius／位移／高度分別只改對應尺寸或行程；頂部與底部始終同寬。
- 前搖結束取樣位置與完整瞄準角度；XYZ 偏移與波牆一起旋轉。空中不貼地，出手後落地／轉向不拖動波牆；局部高度範圍外的受擊 Collider 中心不命中。
- 近／遠敵人按抵達時機各受傷一次；多 Collider 去重、跨 Tick 高速掃掠及遮擋保留。
- Client 收到 Host 發射點、完整旋轉、半徑、高度與距離；晚加入接續、重連不補播，Input Authority 沿原路由。
- 死亡、卸裝、Despawn、完成位移後無殘留主波。
- 自動測試、受控 Runner、獨立程序、自然玩法、美術接受度分別列在[本次紀錄](Validation/ShockwaveAim/README.md)。
