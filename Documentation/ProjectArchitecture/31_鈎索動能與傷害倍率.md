## 責任與資料流

`Player.FixedUpdateNetwork` 取得輸入後呼叫動能的 `TickSimulation`。動能讀取 PlayerMovement 世界速度，以及 PlayerGrapple 的普通拉動／釋放動能狀態，更新 Networked `NormalizedEnergy`。此流程沿用玩家預測 Simulation；不能把它描述成只在 State Authority 執行。

傷害透過 `DamageReceiverUtility` 的 `IOutgoingDamageModifier` 取得倍率。只修改 Bullet、Melee 的正數 `RequestedDamage`，不改 `BaseDamage`，不介入治療、環境傷害或鈎索充能次數。

## 目前預設規則

| 設定 | 預設 |
|---|---|
| 普通鈎索拉動期間充能 | 開啟，獨立 Inspector 開關 |
| 斷繩後釋放動能期間充能 | 開啟，獨立 Inspector 開關 |
| 充能速度門檻 | 世界速度 ≥ 100 |
| 從空到滿 | 10 秒 |
| 靜止判定 | 世界速度 ≤ 0.1 |
| 無法充能且靜止時，從滿到空 | 2 秒 |
| 無法充能但仍移動時，從滿到空 | 6 秒 |
| 滿能量傷害倍率 | ×2；從 ×1 線性增加 |
| 最高強化保持 | 滿能量後 1.5 秒；期間再次達成滿能量條件會刷新，無冷卻、不疊加 |

能量限制在 0～1；0 秒充能時間代表立即充滿，0 秒衰退時間代表立即清空。到達滿值時建立 1.5 秒 `TickTimer`，保持期間能量與傷害倍率固定滿值；若仍符合滿能量充能條件，Timer 會刷新而不增加第二層倍率。停止觸發後保持時間結束，才依快／慢衰退規則下降。新生成的 State Authority 初始化為零，不跨死亡保留。

## 結果通知與 HUD

2026-09-26 局部新增：本地 `BulletTracerLineDrawer` 透過職業 Runtime 的正式 Owner 只讀 `NormalizedEnergy`；達到 1 的新射擊切換滿動能基礎色。每發取樣一次，不改充能／傷害結果；設定與驗證見 [50](50_武器瞄準與射擊.md)。

Receiver 結算、拒絕或 FullyBlocked 會各通知來源 Listener 一次；NoReceiver 不通知。`HandleTargetKilled` 目前是空的擴充入口，**沒有實作擊殺減冷卻或恢復鈎索次數**。

詳細診斷 HUD 僅顯示本機 Input Authority，由 DevelopmentToolsPolicy 限制在 Editor／Development Build，Phase 4 前置-3 起預設關閉。正式中下方 HUD 的量條只讀 `NormalizedEnergy`，不再顯示速度；最高強化期間維持滿條，文字顯示 `傷害增加100%` 並放大、改色，詳見 [146](146_PrePhase4-3_HUD排列與資訊精簡.md)。

## 2026-09-19 最高強化細節

`PlayerGrappleMomentumEnergyRules` 是無場景依賴的單步計算：充能到滿要求刷新保持 Timer；保持中再次充能只刷新 Timer；沒有充能時保持滿值直到 Timer 結束；結束後才衰退。`PlayerGrappleMomentumEnergy` 仍由原有預測 Simulation 呼叫，不新增 RPC 或平行傷害系統。

## 驗證邊界

EditMode 回歸測試覆蓋共用傷害入口的倍率、BaseDamage 保留、通知次數與拒絕／格擋；不涵蓋 Fusion 預測、低幀率、輸入遺失或 Host／Client 的能量一致性。後續實機驗證需觀察 HUD 與權威傷害結果。
