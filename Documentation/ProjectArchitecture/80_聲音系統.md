# 聲音系統架構

> 最後核對：2026-09-14  
> 相關文件：`50_武器瞄準與射擊.md`、`60_傷害生命死亡與回饋.md`、`70_第一人稱模型與動畫.md`

## 兩條播放路徑

```text
本地第一人稱聲音
事件來源 → GameplayAudioService → FirstPerson Mixer Group

世界可聽聲音
State Authority／武器事件
→ NetworkPlayerAudioEmitter
→ 各 Client 的 GameplayAudioService
→ World Mixer Group，跟隨發聲 NetworkObject
```

## 程式職責

| 程式 | 職責 |
|---|---|
| `GameplayAudioCue.cs` | 單一音效 Cue 設定，包含 Clip、音量、音高、播放方式與 Network Delivery 類型 |
| `GameplayAudioCatalog.cs` | 集中保存可重用 Cue，提供武器、傷害與移動系統引用 |
| `GameplayAudioService.cs` | 本機音效播放中心；管理一次性、跟隨型 One Shot 與持續 Loop |
| `NetworkPlayerAudioEmitter.cs` | 將世界聲音透過網路送到所有玩家，並以發聲者 NetworkObject 作為跟隨座標 |
| `FirstPersonAnimationAudioEvents.cs` | Animator Event 播放本地換彈、拉槍機、武器機械細節音 |
| `FirstPersonMovementAudioController.cs` | 本地走路、跑步、跳躍、落地、滑鏟、鈎索／飛行風聲與 Loop 狀態 |
| `FirstPersonDamageFeedbackAudio.cs` | 本地命中、暴頭、擊殺回饋音與優先序 |

## Audio Mixer 建議樹

```text
MainAudioMixer
└─ SFX
   ├─ FirstPerson
   └─ World
```

- `Local First Person Fallback Group` 指到 `MainAudioMixer/SFX/FirstPerson`。
- `World SFX Fallback Group` 指到 `MainAudioMixer/SFX/World`。
- Fallback 是 Cue 未指定 Mixer Group 時的預設輸出，不是新的 Audio Mixer 資產。

## 路徑判斷

| 聲音 | 路徑 |
|---|---|
| 換彈拉槍機、第一人稱手部細節 | Local First Person |
| 本地走路、跑步、滑鏟、風聲 | Local First Person |
| 命中／暴頭／擊殺提示 | 攻擊者 Local First Person |
| Attack／Support 槍聲 | Network World，且跟隨射手 |
| Tank 普攻／特殊攻擊世界聲 | Network World |
| Enemy 攻擊聲 | Network World |

槍聲 One Shot 不能留在開槍瞬間的固定世界座標。射手移動時，聲源在生命期內必須跟隨射手；`GameplayAudioService` 的 Following One Shot 與 `NetworkPlayerAudioEmitter` 負責此行為。

## 擴充規則

- 新增聲音先建立／指定 `GameplayAudioCue`，不要讓每支能力自行建立 AudioSource 池。
- 需要所有人聽見才經過 Network Emitter；不要廣播第一人稱細節音。
- 持續聲音必須有明確 Start、Update 跟隨與 Stop／Despawn 清理路徑。
- 只根據權威 DamageResult 播命中回饋，並維持擊殺 > 暴頭 > 命中。
