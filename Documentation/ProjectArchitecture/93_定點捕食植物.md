> 最後核對日期：2026-10-17（局部核對：單人／多人皆可武器反擊）  
> 核對來源：EnemyFlytrapAttack／Strike／StrikePhysics／Rules／Presentation、PlayerActionGate.Capture、Player、PlayerMovement、PlayerAbilityRuntime、PlayerProfessionRuntimeManager、SupportGrapplePlayerPullReceiver。  
> 相關文件：[90 敵人核心](90_敵人核心感知巡邏與追逐.md)、[91 戰鬥仲裁](91_敵人攻擊表現與生成.md)、[20 玩家移動](20_玩家核心移動與狀態.md)、[60 生命](60_傷害生命死亡與回饋.md)。

## 已確認玩法

- 原地等待、不巡邏或追逐，周圍 360 度、有限距離感應，不隔牆。指定前還要檢查完整玩家膠囊的拉入路徑與嘴邊終點占用；不通則不指定。
- 安靜站著不動安全；站著移動觸發。蹲行且不開槍／不用鉤索安全，滑鏟不算安全蹲行。成功射擊或正在使用鉤索會觸發；空槍不觸發射擊通知。
- 蓄勢前段追蹤玩家，出手前短暫固定方向，藤蔓沿固定直線快速刺出，不轉彎。發現／蓄勢／出手不封鎖玩家操作；玩家可側移、鉤索離開或利用掩體。
- 藤蔓抓住路徑上第一個實際命中的玩家，不限原先目標；蹲行只影響感應，仍可被藤蔓攔截命中。碰牆先阻擋，落空則收回並完成獨立收招。
- 一次一人；同一玩家不能同時被兩隻捕食。實際命中並再次確認完整拉入路徑暢通後，才立即封鎖移動、瞄準／右鍵能力、Q／E／F 等技能，停止既有滑鏟、鉤索、武器動作與啟動中的能力；保留轉動視角。單人與多人都允許重新主武器攻擊與換彈，仍須遵守其他來源的控制鎖。
- 命中前可閃避；成功抓住後快速拉到嘴邊，不再提供掙脫窗口。**實際抵達嘴邊**才開始吞食計時。拉動不扣血。
- 房間只有一名玩家時總傷害 = 最大生命值 50%；房間另有玩家時 = 100%，死亡隊友仍計入房間人數。房間容量不等於實際房間人數。
- 吞食預設 5 秒、每 0.5 秒直接扣生命，共 10 次，第 0.5 秒首次扣血。略過護盾與減傷，但沿用 PlayerHealth 的受傷回饋、來源與正式死亡。
- 總時間與間隔皆可調，總比例不變。不能整除時，最後不足一段的傷害於總時間結束結算；間隔大於總時間時，只在結束結算。
- 殺死怪物立即解救，停止所有未付傷害。普通受擊不解救。目標死亡或吞食結束釋放後都冷卻 10 秒。

## 原型實作決策及邊界

- 追蹤時目標死亡／斷線或失去視線，進入收招；方向固定後不再追蹤，原目標離開或死亡不取消已承諾的直線刺出，仍可命中路上其他玩家。
- 藤蔓前端逐 Tick 連續球形掃掠，補查起點重疊，避免高速穿過薄牆；環境依 Obstacle Mask，玩家獨立辨識 Collider，不要求玩家加入環境遮罩。等距牆優先，玩家子 Collider 歸屬同一根物件。
- 第一接觸玩家若已被其他捕食者抓住、已死亡、所屬 Runner 不符或拉入路徑被擋住，本次收招，不穿過他改抓下一人。命中不額外造成碰撞傷害。
- 新原型節奏：追蹤 0.5 秒、固定方向提示 0.25 秒、速度 30 m/s、射程 8 m、半徑 0.15 m、落空收招 0.8 秒；皆可調，未視為最終平衡。

- 成功命中抓取時快照實際房間人數、最大生命值、總時間與間隔，途中離線、治療或調整參數不重算該次總額。治療不被禁止，因此多人總額 100% 不保證有外部治療時仍必死。
- 尚未指定時最近的合法玩家優先；開始蓄勢時固定追蹤對象，命中前不取得玩家的捕食鎖。槍聲通知保留兩個 Fusion Tick，避免更新順序漏掉單發射擊，不是持續警戒記憶。
- 拉動採直線 KCC 位移，保留碰撞解算。若指定後動態障礙插入造成超過「拉動秒數 + 2 秒」仍未抵達，安全釋放並冷卻，不穿牆或永久卡住。這是異常幾何保護，不是操作閃避設計。
- 所有釋放（正常完成、擊殺解救、異常中止／Despawn）均在當前位置解除捕食鎖並清除捕食速度；不回到捕捉位置，不另設傳送／拋出位移，後續由原 KCC 與重力接手。
- 方塊原型未掛 Support Pull／Tank Gather Receiver，並關閉既有 EnemyStateController.AllowAbilityKnockback，以維持原地扎根及擊殺解救規則；技能的原始傷害仍照常。子彈時間仍沿用既有暫停規則。
- 已發射到世界的子彈、投射物不因射手被困而抹除。被困者的技能持續封鎖，單人／多人皆僅允許主武器及換彈；尚未完成的 E 施放經既有不可用／結束入口取消；既有冷卻與裝備保留。
- 主武器資格由 Host 在成功抓住時同步開啟，不再隨房間人數變動；隊友加入／退出不取消正在進行的攻擊或換彈。房間人數只參與抓取時的吞食傷害快照，既定總額不重算。
- Tank 單人／多人皆可預備與原地揮擊；放開預備不啟動接近敵人的武器衝刺，已在衝刺時被抓立即取消。F 衝刺、E 能力、右鍵格擋與所有其他位移均維持封鎖；受困時近戰方向跟隨實際瞄準（可向下攻擊嘴邊敵人），其餘狀態保留水平 Yaw；仍使用既有距離、扇形與 LOS，瞄偏會揮空，不直接保證傷害。
- 子彈時間順延捕食／拉動計時；解除捕食只解除自己的來源，其他 Death／System／爆炸鎖保留。

## 資產與責任

- Prefab：`Assets/Prefabs/Enemy/Variants/Enemy_Flytrap.prefab`
- Definition：`Assets/_Project_Assets/Data/Enemy/ED_Flytrap.asset`
- 建立入口：`Tools > Purgers > Enemy > Create Missing Flytrap Placeholder`。只建立缺少資產，不覆寫人工調整、不放置 Scene、不改生成器。
- `EnemyFlytrapAttack : EnemyCombatOption` 透過既有 Decision 的近身感應入口取得唯一攻擊鎖。獨立查詢本 Runner 的合法玩家，不沿用共用視野角、警戒記憶或追逐。
- `PlayerActionGate.Capture` 保存同步 Captor／受困旗標／位移目標／受困武器資格；ReleaseCapture 不再接收釋放位置。Player 透過 FilterCapturedInput 僅保留 Fire／Reload，且不恢復其他控制鎖已移除的按鍵；Player 過濾主動輸入，PlayerMovement 在既有 KCC PrepareData 接管位移。沒有第二套移動或生命系統。
- `EnemyFlytrapAttack.Strike` 在同一攻擊仲裁內管理 Tracking／Locked／Striking／Recovering；同步方向、起點、前端、進度及瞄準目標。`EnemyFlytrapStrikePhysics` 沿用 ActiveAbilityPhysics 的 Runner 查詢，選擇第一個接觸。
- `EnemyFlytrapRules` 是純觸發與累計傷害比例規則。傷害由 Host 送入原 PlayerHealth.ReceiveDamage，無新增直接改 HP 的 API。
- `EnemyFlytrapPresentation` 只讀同步狀態、序號與生命；不回寫傷害、抓取成功或死亡。晚加入不重播歷史咬合／釋放。
- 玩家 ActionGate 新增 Networked 欄位，需要相同版本 Host／Client，舊連線不能熱更新。

## Inspector 手動配置

| 位置 | 起始值 | 範圍／效果／依賴 |
|---|---:|---|
| Enemy Combat Option / Maximum Start Distance | 6 m | 原型值，與玩家 Root 的三維距離；場景顯示範圍 Gizmo |
| Test Damage Receiver / Max Health | 100 | 原型值，非已驗收平衡 |
| Mouth Anchor | MouthAnchor_PlayerFeet | 玩家**腳底**固定點，須留完整站立膠囊空間，不可埋入模型或天花板 |
| Sense Origin | SenseOrigin | 視線起點，空值退回嘴邊 |
| Tendril Origin | TendrilOrigin | 藤蔓發射掛點；既有 Prefab 留空時自動找同名掛點 |
| Tracking Seconds / Locked Seconds | 0.5 / 0.25 s | 前段追蹤、後段固定方向；各至少一 Tick |
| Use Strike Frame Timing | false | 共用 AnimationFrameTiming；Lock Direction Frame 12、Launch Frame 18（24 FPS），須出手幀晚於固定方向幀；無效時退回秒數 |
| Vine Speed / Range / Radius | 30 m/s / 8 m / 0.15 m | 直線伸出速度、最大長度、碰撞半徑；與感應距離分離 |
| Miss Recovery Seconds | 0.8 s | > 0，落空／撞牆／無法拉入時收回收招；與成功吞食後冷卻分離 |
| Show Placeholder Vine | true | 本機無碰撞方塊藤蔓；正式模型替換時可關閉 |
| Pull Seconds | 0.2 s | 至少一 Tick；原型值，可依尺寸與第一人稱感受調整 |
| Use Animation Frame Timing | false | 有正式動畫後可啟用，沿用 AnimationFrameTiming；Arrival Frame 為抵達幀，0 起算 |
| Movement Epsilon | 0.05 m/s | 只排除站立抖動；移動輸入本身也會觸發，不能當高速門檻 |
| Obstacle Mask | Default | 必須包含實際牆、欄杆、環境碰撞 Layer；查詢使用 Runner PhysicsScene |
| Feeding Seconds | 5 s | > 0，抵達嘴邊才起算；開始時快照 |
| Damage Interval Seconds | 0.5 s | > 0，第一間隔後扣血；不足一段於結束結算 |
| Cooldown Seconds | 10 s | >= 0，存活釋放／目標死亡共用 |

1. 先開啟 Prefab 檢查掛點與範圍，保留人工數值；原型資產只有一個方塊 Renderer 和一個 Hitbox；執行時額外建立無碰撞的本機方塊藤蔓。
2. 在需要的位置手動配置既有 EnemySpawnZone，混合清單加入本 Prefab，Locomotion Kind 自動辨識 Stationary。敵人在出生 Box 內隨機散布，不自動貼地；請自行配置盒體高度與可放置的範圍。不需要 Patrol Area；若使用舊版空混合清單，仍可在舊設定選 Stationary 與 Enemy Prefabs。
3. 確認 Obstacle Mask 包含地圖的實際環境 Layer，並從各方向檢查玩家到嘴邊的完整身體路徑。
4. F4 開發測試生成器可用既有 Stationary Spawn Point；需手動指定 Prefab 候選，不自動改原有候選清單。
5. 進入 Play Mode：安靜站立／蹲行安全，站走／射擊／鉤索觸發；先看到蓄勢追蹤與固定方向，可側移躲開；實際命中才拉到嘴邊，再看到第一間隔扣血。
6. 分別驗證單人、房內兩人、一位隊友已死、擊殺解救、低血量提前死亡、玩家斷線、怪物 Despawn、跨關卡清理。

### 2026-10-17 手動驗收補充

- 單人與多人被捕後，轉動視角瞄準怪物，用主武器攻擊及換彈；Q／E／F／右鍵能力、移動、跳躍仍應無效。
- Tank 按住到預備停格再放開，應原地出手，不能衝向其他敵人；抓取打斷已開始的衝刺。
- 正常吞食結束、擊殺解救、怪物 Despawn 都留在解除當下的位置；若掛點在空中，釋放後由原 KCC 自然落下。
- 第二人加入、離開或重連都不改變受困武器資格，正在預備的 Tank 攻擊不因此中止；捕食傷害比例仍使用本次抓取快照。
- 本輪無需新增 Inspector 欄位或重新配置 Scene／Prefab；Host／Client 必須使用同版程式。

## 動畫接口與製作清單

必要動作：待機循環、發現／追蹤蓄勢、固定方向待發、藤蔓刺出、落空收回／收招、抓取／拉回、吞食循環、釋放、冷卻循環、受擊、死亡。可選：冷卻結束張口、吞食成功收尾。

Prefab 預留 `VisualRoot`、`MouthAnchor_PlayerFeet`、`SenseOrigin`、`TendrilOrigin`。替換 VisualRoot 模型時保留正式碰撞與 Hitbox／Root 引用；不增加 NetworkObject 到本機視覺。

Animator 可空；指定後使用以下參數，不存在的參數會略過：

| 參數 | 類型 | 意義 |
|---|---|---|
| FlytrapPhase | int | 0 待機、1 拉入、2 吞食、3 冷卻、4 死亡；新增 5 追蹤、6 固定方向、7 刺出、8 收招，保留舊數值 |
| StrikeProgress | float | 0～1，目前追蹤／固定方向／刺出／收招階段進度 |
| PullProgress | float | 0～1，同步拉入進度 |
| FeedingProgress | float | 0～1，同步吞食進度 |
| Bite | trigger | 本機觀察到新扣血序號 |
| Release | trigger | 本機觀察到新釋放序號 |
| Hurt | trigger | 本機觀察到生命降低，建議局部疊加 |

也可接 On Phase Changed／On Bite／On Release／On Hurt UnityEvent。Animator Root Motion 應關閉，動畫不決定捕食成功、扣血與解救。吞食與冷卻必須可循環；拉入事件幀採共用幀時序，但吞食總時間與間隔仍由設定驅動。

藤蔓提示顏色：黃追蹤、橘紅固定方向、紫刺出、褐收招、橙拉入。方塊本體材質仍可能受既有 EnemyDamageFlash 的材質槽控制，不以本體換色作為唯一提示。本機方塊藤蔓蓄勢從方塊表面伸長並指向目標（只移動提示，不改發射掛點），固定方向後停止跟隨，之後依同步前端伸出／收回。保留 On Phase Changed 接正式動畫與提示音，未新增音效素材。這是可觀察狀態的原型，未建模、未提供正式動畫 Clip／Animator Controller。
