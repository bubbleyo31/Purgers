## Animator 建置原則

- 遊戲狀態是來源，Animator 是消費者。不要依 `AnimatorStateInfo` 反推是否已射擊或造成傷害。
- `Appear` 是職業 ViewModel 顯示時播放的進場動畫，保留未來其他顯示情境重用。
- Shoot／Reload／Melee 的 Trigger 或序號由 Driver 讀取武器／能力狀態後設定。
- Aim 使用單一可逆動畫：正速度開鏡，最後維持瞄準 Pose；負速度關鏡。
- Aim 時只壓制 Idle Motion、Walk Bob、Sway 等位置干擾，不要把 `FirstPersonViewModelMotionProfile` 資產改寫成零。
- Animation Event 可播放本地細節音，但權威傷害時機仍使用 Tick／攻擊程式的 Active Window 或實際武器接觸。

## Spawn 時序防護

職業切換可能先顯示 ViewModel，武器 `NetworkBehaviour.Spawned()` 才稍後完成。Driver 在讀取 Networked 狀態前必須確認 `Object != null && Object.IsValid`。尚未 Spawn 時應維持安全 Idle／不更新，而不是存取 `ShotSequence`、Reload State 或 `CurrentAimPhase`。

## 動畫速度與遊戲時間

**2026-10-10 使用者定案**：未來新增或修改玩家武器、技能及敵人的動畫出傷／事件時機，統一使用原始總秒數、來源 FPS、播放倍率及指定幀，由共用 AnimationFrameTiming 自動換算；Inspector 顯示換算結果，不要求使用者自行計算事件秒數。完整規則、倍率責任及現有 Tank 設定見 [47 共用動畫幀時序](47_Tank預備攻擊與動畫幀時序.md)。目前僅 Tank 接入，其他系統尚未遷移。

- 動畫倍率公式：`實際播放時間 = Clip 長度 ÷ Animator 播放倍率`。
- 原 Clip 第 N 幀的原始秒數：`N ÷ Clip FPS`；若整段加速，實際秒數再除以倍率。
- 網路傷害判定不要完全依賴 Animation Event，Event 可負責模型武器 Collider 開窗或本地音效回饋。

## 2026-10-17 換彈鏡頭旋轉（局部核對）

最後核對日期：2026-10-17。核對來源：FirstPersonReloadCameraMotion、ReloadCameraMotion、FirstPersonViewModelActionAnimator、FirstPersonHitCameraShake、InputManager、PlayerMovement。
相關文件：[50 武器](50_武器瞄準與射擊.md)、[驗證與限制](Validation/ReloadCamera/README.md)。

### 已確認範圍與資料流

兩把槍使用既有右手下的槍械 Root，只取旋轉；每把槍各自調整幅度，快速轉頭時減弱。玩家視角輸入、KCC Look、換彈計時、彈藥、FOV、位置及網路權威均不由此效果改寫。兩把槍 Prefab 已依後續授權自動接線；沿用既有 Scene 鏡頭入口。觀戰遠端角色本輪不播放這項效果。

可選 FirstPersonReloadCameraMotion 掛在各 ViewModel Prefab 根物件，讀同物件 ActionAnimator 已綁定的本機 Rifle／SMG 換彈狀態及 Owner；來源須 Spawned、具有 Input Authority、為目前觀看的本機角色且存活。BindingVersion 在 Bind／Unbind 遞增，避免同角色更換 Runtime 沿用舊基準。

Update 捕捉新一輪換彈前的 Root 姿態；Animator 求值後於 LateUpdate -50 取樣。姿態使用 `inverse(animatedModelRoot.rotation) * weaponRoot.rotation`，包含右臂父骨骼的動作、排除共同祖先的玩家轉向與鏡頭效果。Root 本身的 localRotation 固定，不能只讀該值。起始時捕捉模型到效果節點的座標轉換，把旋轉偏移轉為相機軸向後套用倍率與角度上限；採最短軸角向量避免 Euler 角跨 360 度跳動。

InputManager.CurrentFrameLookDelta 只讀同幀已收集的 LookDelta，過期／清除／封鎖時回零，不消耗 Fusion 累積輸入。乘 PlayerMovement.LookSensitivity 並除以 unscaledDeltaTime 得到玩家輸入角速度，平滑降低效果權重。角度先限幅再減弱，避免幅度飽和時快速轉頭失效。跟隨及退場使用 unscaledDeltaTime 指數平滑；取樣仍跟隨實際 Animator，因此既有換彈速度倍率自然生效，不建立第二個換彈時鐘。

FirstPersonHitCameraShake 維持效果 Transform 的唯一寫入責任，旋轉合成順序為 authored base × reload × hit shake。既有震動 Coroutine 與 Reset 只清自己的震動，保留換彈；清理以 owner 比對，舊 ViewModel 不能清掉替換後的新效果。效果在 CameraFollow 更新及 AfterCameraUpdated 事件前提交，不改相機跟隨對象。

正常完成／取消只將最後的換彈偏移平滑退回零，不追蹤接下來的近戰／射擊動畫，也不把玩家拉回換彈前方向。死亡、來源失效、換裝／解除綁定或元件停用立即移除自身效果。中途加入已進行中的換彈不補播，等下一次換彈再捕捉基準。

### 人工驗收
