## Animator 建置原則

- 遊戲狀態是來源，Animator 是消費者。不要依 `AnimatorStateInfo` 反推是否已射擊或造成傷害。
- `Appear` 是職業 ViewModel 顯示時播放的進場動畫，保留未來其他顯示情境重用。
- Shoot／Reload／Melee 的 Trigger 或序號由 Driver 讀取武器／能力狀態後設定。
- Aim 使用單一可逆動畫：正速度開鏡，最後維持瞄準 Pose；負速度關鏡。
- Aim 時只壓制 Idle Motion、Walk Bob、Sway 等位置干擾，不要把 `FirstPersonViewModelMotionProfile` 資產改寫成零。
- Animation Event 可播放本地細節音，但權威傷害時機仍使用 Tick／攻擊程式的 Active Window 或實際武器接觸。

## Spawn 時序防護

職業切換可能先顯示 ViewModel，武器 `NetworkBehaviour.Spawned()` 才稍後完成。Driver 在讀取 Networked 狀態前必須確認 `Object != null && Object.IsValid`。尚未 Spawn 時應維持安全 Idle／不更新，而不是存取 `ShotSequence`、Reload State 或 `CurrentAimPhase`。

## 動畫速度與遊戲時間

**2026-10-10 使用者定案**：未來新增或修改玩家武器、技能及敵人的動畫出傷／事件時機，統一使用原始總秒數、來源 FPS、播放倍率及指定幀，由共用 AnimationFrameTiming 自動換算；Inspector 顯示換算結果，不要求使用者自行計算事件秒數。完整規則、倍率責任及現有 Tank 設定見 [47 共用動畫幀時序](47_Tank預備攻擊與動畫幀時序.md)。目前僅 Tank 接入，其他系統尚未遷移。

- 動畫倍率公式：`實際播放時間 = Clip 長度 ÷ Animator 播放倍率`。
- 原 Clip 第 N 幀的原始秒數：`N ÷ Clip FPS`；若整段加速，實際秒數再除以倍率。
- 網路傷害判定不要完全依賴 Animation Event，Event 可負責模型武器 Collider 開窗或本地音效回饋。
