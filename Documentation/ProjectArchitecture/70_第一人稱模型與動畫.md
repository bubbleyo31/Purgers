# 第一人稱 ViewModel 與動畫架構

> 最後核對：2026-09-14  
> 相關文件：`50_武器瞄準與射擊.md`、`80_聲音系統.md`

## 顯示與驅動流程

```text
PlayerLocalView（確認本機玩家）
→ ProfessionViewModelManager（只顯示目前職業模型）
   ├─ WeaponViewModelReferences（該模型的引用集合）
   ├─ FirstPersonViewModelActionAnimator
   ├─ FirstPersonViewModelAimAnimator
   ├─ FirstPersonTankViewModelAnimator
   └─ FirstPersonViewModelMotionController
```

## 程式職責

| 程式 | 職責 | 讀取來源 |
|---|---|---|
| `ProfessionViewModelManager.cs` | 管理 Attack／Support／Tank 第一人稱模型啟用、職業切換、Appear 與各 Animator Driver 綁定 | Profession Runtime、武器、能力 |
| `WeaponViewModelReferences.cs` | 每個 ViewModel 的 Animator、Root、武器節點與 Driver 引用集合 | Manager 與 Drivers |
| `FirstPersonViewModelActionAnimator.cs` | Idle、Shoot、Reload、Melee、Appear 等武器動畫狀態 | AttackRifle、SupportSMG、Quick Action、Action Gate |
| `FirstPersonViewModelAimAnimator.cs` | Aim 開鏡動畫正播到目標姿勢；取消時以負速度倒播 | PlayerAimController |
| `FirstPersonTankViewModelAnimator.cs` | Tank 三段近戰、防禦、Quick Dash／Air Dash／特殊能力與進場動畫 | Tank abilities、Combo |
| `FirstPersonViewModelMotionProfile.cs` | ScriptableObject，保存 Idle Motion、Walk Bob 等程序式位移參數 | Motion Controller |
| `FirstPersonViewModelMotionController.cs` | 依移動狀態與 Profile 疊加第一人稱武器位置／旋轉；Aim 時暫停會干擾瞄準的位置運動 | Movement、State、Aim Animator |
| `FirstPersonAnimationAudioEvents.cs` | Animator Event 觸發本地第一人稱細節聲音 | GameplayAudioService |

## Animator 建置原則

- 遊戲狀態是來源，Animator 是消費者。不要依 `AnimatorStateInfo` 反推是否已射擊或造成傷害。
- `Appear` 是職業 ViewModel 顯示時播放的進場動畫，保留未來其他顯示情境重用。
- Shoot／Reload／Melee 的 Trigger 或序號由 Driver 讀取武器／能力狀態後設定。
- Aim 使用單一可逆動畫：正速度開鏡，最後維持瞄準 Pose；負速度關鏡。
- Aim 時只壓制 Idle Motion、Walk Bob、Sway 等位置干擾，不要把 `FirstPersonViewModelMotionProfile` 資產改寫成零。
- Animation Event 可播放本地細節音，但權威傷害時機仍使用 Tick／攻擊程式的 Active Window 或實際武器接觸。

## Spawn 時序防護

職業切換可能先顯示 ViewModel，武器 `NetworkBehaviour.Spawned()` 才稍後完成。Driver 在讀取 Networked 狀態前必須確認 `Object != null && Object.IsValid`。尚未 Spawn 時應維持安全 Idle／不更新，而不是存取 `ShotSequence`、Reload State 或 `CurrentAimPhase`。

## 動畫速度與遊戲時間

- 動畫倍率公式：`實際播放時間 = Clip 長度 ÷ Animator 播放倍率`。
- 原 Clip 第 N 幀的原始秒數：`N ÷ Clip FPS`；若整段加速，實際秒數再除以倍率。
- 網路傷害判定不要完全依賴 Animation Event，Event 可負責模型武器 Collider 開窗或本地音效回饋。
