## 1. 入口、小選單與視覺

遊戲按 ESC 先開小選單，不直接開設定。依序為「返回遊戲」「設定」、房主的「離開並保存遊戲」或其他玩家的「離開遊戲」。底部為房間號與複製按鈕；平常隱藏，未連線不顯示。每次開啟預選返回遊戲。

設定返回小選單，小選單返回遊戲；主選單右上角直接開共用設定，返回主選單。兩入口共用資料。

世界與一般 HUD 上方、選單下方加黑色 60% 不透明遮罩；小選單與設定共用，不重複疊黑。彈窗再壓暗後方介面，僅最上層可操作；點黑色背景不關閉。

使用深橄欖純色底、米白字與金色線條，不使用筆刷底圖。選取為金黃純色底＋深色文字＋左側標記，未選米白；未配置的警告不能被選取樣式遮掉。

滑鼠移入選取／左鍵確認、滾輪上下、方向鍵上下及 Enter 確認共用單一選取狀態；首尾不循環。設定頁滑桿、下拉與捲動區依自身用途，不套用小選單滾輪切項。

## 2. ESC 優先序

同一次按鍵只執行一件事；載入／轉場既有封鎖優先：

1. 改鍵等待中：取消此次改鍵。
2. 安全屋投票／出發倒數中：取消整次投票／倒數。
3. 其他：處理最上層彈窗、設定返回、小選單關閉或開啟小選單。

投票中第一次 ESC 不開選單，第二次才開。選單已開啟而後有投票，ESC 先取消投票、原選單保留。TAB 準備／取消自己準備沿原規則；Host／State Authority 驗證正式取消。

## 4. 操作模式

| 動作 | 初始模式 | 按住 | 切換 |
|---|---|---|---|
| 鈎索 | 切換 | 按住啟動維持，放開解除 | 按下發射，再按解除 |
| 瞄準 | 按住 | 按住瞄準，放開解除 | 按下啟動，再按解除 |
| 跑步 | 切換 | 按住且有移動才跑，放開解除 | 按下啟動，再按取消；停止移動也解除 |

跑步保留加速；蹲下／滑鏟保留原判定，頭頂障礙阻止站起；鈎索保留自動釋放條件，Aim 不取消鈎索。這些設定不繞過 ActionGate、控場、技能或權威仲裁。

## 5. 數值控制與預設

| 項目 | 範圍 | 初始值 | 刻度 |
|---|---|---|---|
| 總靈敏度 | 0.10–5.00 | 1.00 | 0.01 |
| 水平倍率 | 0.10–2.00 | 1.00 | 0.01 |
| 垂直倍率 | 0.10–2.00 | 1.00 | 0.01 |
| 總音量／音效／音樂 | 各 0–100% | 各 100% | 1% |

目前手感為 1.00 基準，水平＝既有基準×總靈敏度×水平倍率，垂直同理；不可把 Prefab 原靈敏度強制改為 1。不可設零。音量 100% 保留素材原比例。

可調數值有名稱、拖曳滑桿、可直接輸入的數值框與單位；超界提示並限制合法範圍。焦點滑桿用左右鍵細調。幀率用離散刻度＋數值，另有不限制；解析度／畫質等組合選項保留下拉。

## 6. 按鍵清單與群組

第一版每操作／群組一個綁定，支援鍵盤、滑鼠左／右／中／側鍵；不提供組合鍵，滾輪保留介面用途，不綁玩法。

| 操作／群組 | 初始鍵 |
|---|---|
| 前／後／左／右 | W／S／A／D |
| 跳躍 | Space |
| 跑步 | Left Shift |
| 蹲下／滑鏟 | Left Ctrl |
| 使用鈎索／Q 鈎索能力 | Q，共用綁定 |
| E 技能／情境互動／救援 | E，共用綁定 |
| 瞄準／主武器攻擊 | 滑鼠右鍵／左鍵 |
| 換彈／武器特殊動作 | R／F |
| 獎勵選擇／展開小地圖／隊伍資訊與準備切換 | Left Alt／M／Tab |

Q／E 群組改一次，全群組與提示同步；同群組不是衝突，也不是同時觸發全部功能，沿原情境與時機。移動改鍵連同 A／D 連按側移等衍生操作更新。

ESC 固定保留。Y 僅於設定情境確認，可綁玩法；等待改鍵時 Y 只綁定，不保存。開發測試鍵不列入設定。

## 6.1 後續新功能／按鍵輸入的必要同步（2026-10-18 定案）

新增、修改或移除正式玩家操作時，ESC「設定 → 自訂按鍵」必須在同一批功能變更中同步完成；不能只讓新功能讀取固定按鍵，卻未進入設定按鍵庫。主選單與遊戲 ESC 共用同一套資料，不另建按鍵來源。

- 新獨立操作：同步操作識別、名稱、預設鍵、實際輸入讀取與自訂按鍵列；確認新增項目可見、可選取，數量增加時調整清單版面或捲動，不能超出畫面。
- 沿既有 Q／E 等共用群組的功能：接入該群組綁定，更新群組說明與使用處，不建立互相衝突的重複項目。衍生操作也跟隨已改鍵的來源。
- 所有相關 HUD、鍵帽圖片、文字、教學與互動提示都從同一綁定來源更新，不能殘留寫死的舊鍵。
- 同步衝突清空、未配置警告、Y／按鈕確認、保存／讀取與重設初始值；維持 ESC 固定保留與既有情境規則。純 Editor 開發測試鍵仍不列入玩家設定。
- 新增／移除操作須處理既有本機設定相容性：保留玩家原改鍵，不可因陣列長度或列舉順序變更而整批重設、錯位或靜默搶用舊鍵；明確處理新操作的預設／衝突與移除項目。
- 驗收同時確認：設定列可改、實際操作使用新鍵、提示同步、衝突／空白處理、保存重開及重設；涉及網路輸入時另驗證每玩家綁定與權威責任。功能未完成這些同步，不算完成。

目前入口為 PlayerBinding／PlayerSettingsData、PlayerSettingsSession.Actions、PlayerSettingsMenu.Bindings、PlayerSettingsService 與 InputManager／既有情境輸入讀取處。本節是後續開發必守規則，不代表已新增自動掃描功能或完成任意未來操作的資料遷移；本次只收錄規則，未改程式與場景。
## 7. 衝突、空白與圖片提示

新綁定取得鍵，舊使用者（整個操作／群組）清空，不交換、不自動補回預設。空白整列暗紅背景＋警告圖示＋「未配置」，底部顯示未配置數量。重新配置解除警告。

允許空白保存，但保存彈窗列出全部未配置項目並提醒無法由按鍵觸發。群組清空則全群組失去綁定。

UI 圖片與文字共用綁定資料：鍵盤鍵帽／滑鼠圖示、Q／E、救援、互動、換彈、準備等同步；保留原外框美術。設定立即預覽，正式 HUD 確認套用後更新。空白顯示「—／未配置」，不殘留舊鍵。

## 8. 草稿、保存與返回

各分頁共用未保存修改，切頁不丟失也不詢問。底部固定 Y／畫面「確認更動」、重設、返回，有修改標記未保存；無修改停用確認。

Y 或按鈕開「儲存此設定？ 是／否」，預選否，開啟的同次按鍵不連帶確認。

| 情境 | 是 | 否 | ESC（前述優先序之後） |
|---|---|---|---|
| 主動確認 | 套用保存，留設定，顯示已保存 | 留草稿繼續編輯 | 同否 |
| 未保存返回 | 保存後返回上一層 | 放棄草稿返回 | 保留草稿繼續編輯 |

失敗留草稿並可重試，不顯示成功、不直接返回。聲音可即時預聽，放棄還原；按鍵／模式確認後才生效。解析度／全螢幕有 15 秒保留確認，未確認還原，不將失敗顯示模式保存為成功。

個人設定存本機，跨場景、房間及重開保留，不綁關卡存檔、不被他人設定覆蓋；不得用 Host 本機偏好代替 Client 的個別意圖。

## 9. 重設

一鍵重設全部玩家設定分頁，先確認；填回初始值、解除空白，仍是草稿，須 Y／按鈕確認保存。放棄則回最後保存值。不清遊戲存檔、不改當前房間。

## 10. 開選單的角色狀態

釋放滑鼠、阻擋新角色操作；瞄準／跑步解除，返回需重啟；鈎索解除，保留慣性與重力、不懸停；蹲下保留姿態，返回依模式接續且受頭頂障礙限制。

不補發選單期間輸入；點擊不穿透為攻擊。之前按住的戰鬥鍵須放開再按，不能關選單自動開火／出鈎。單人多人都不暫停世界，敵人、計時、物理繼續；無無敵、無強制煞停。

## 11. 離開與既有權威

確認預選取消。Host 顯示離開並保存，明示房間將關閉；沿既有存檔流程成功後關房返回主選單。失敗留確認並可重試、不直接離開。Client 顯示離開，只退自己的連線、回主選單，不保存 Host 世界。不是關閉應用程式。

沿用 InputManager → NetInput → Player、LocalPlayerControl 票證、PlayerActionGate、Grapple／Sprint／Slide／Aim 的既有 owner、GameplayAudioService／Mixer、MenuConnection／SessionEnd／既有存檔及轉場。正式玩法由 Host／State Authority 決定；個人偏好、預覽及 UI 不可成為第二套玩法／保存／相機系統。輸入同步、保存位置與實際責任入口見第 13 節；沒有新增玩法 RPC。

## 12. 正式遊戲整合驗收清單（證據與未驗部分分開記錄）

- 焦點切換、三種小選單操作、遮罩層級、ESC 改鍵／投票／彈窗優先序。
- 四模式、開選單釋放與蹲姿、輸入放開再啟動、滑鏟／障礙／慣性；每玩家不同偏好。
- Q／E 群組、側移衍生鍵、全 HUD 圖片、空白衝突與警告保存。
- 草稿／預聽還原、Y 同鍵不穿透、重設、跨場景及重開保存、顯示回滾、I/O 失敗。
- Host 保存關房與 Client 唯讀離開、晚加入／重連、存檔失敗／房間被關閉與 UI 清理。
- 聚焦失敗測試→實作→Unity 編譯／Console→聚焦與非零完整 PurgersRegression；受控 Host／Client、獨立程序、自然鍵鼠、Build 分開記錄。

## 13. 正式實作與設定位置（2026-10-18）

- `PlayerSettingsData` 為 16 個共用綁定、模式與各分頁值；`PlayerSettingsSession` 管草稿、彈窗與顯示回滾；`PlayerSettingsService` 為唯一正式本機偏好來源，保存到 `Application.persistentDataPath/player-settings-v1.json`，暫存後替換並保留 `.bak`。不寫入關卡存檔。讀取失敗使用既有初始值並記錄警告。
- `PlayerSettingsMenu`（含 Runtime partial）負責共用 uGUI、每幀單次 ESC、現有連線／畫質／混音器介接。連線先解開 FusionMenuConnectionBehaviour，再讀同一 MenuConnection；不得把包裝元件誤認成實際 Session。使用最高 Sorting Layer、Order 32000，低於 Loading 32766 與黑幕 32767。取得 Gameplay／Movement／Look 票證，避免使用會停用 EventSystem 的 AllInput。沒有修改 Time.timeScale。
- `InputManager` 從保存設定取鍵，總／軸靈敏度乘在既有 LookDelta 基準上；`PlayerSettingsIntent` 僅記本機瞄準／蹲姿意圖與按鍵放開門檻。`NetInput.SettingsModes` 送出 Valid、GrappleHold、SprintHold 位元，`SettingsMenuOpen` 傳送選單意圖；遠端模擬不讀 Host 本機偏好。
- `PlayerSprintLatchController` 沿既有 Networked 狀態與加速處理切換／按住。`PlayerGrapple.Simulate` 新增可選 holdMode；未提供時保留 Inspector 舊值，正式 Player 使用本 Tick 模式。選單透過原取消入口釋放鈎索並保留動量；原 Slide 控制器保留蹲姿與退出滑鏟時的速度，沒有另一套移動控制。
- HUD Q／E／R／獎勵鍵、救援與安全屋準備鍵帽讀同一綁定；安全屋 E 終端機、準備鍵與小地圖同步改鍵。A／D 衍生側移跟隨方向綁定。ESC 固定；Editor F7／F8 若被正式動作綁定，不額外觸發開發捷徑。
- `MainAudioMixer` 追加 `PlayerMasterVolume`、`PlayerEffectsVolume`、`PlayerMusicVolume` exposed 參數，保留 Master／SFX／FirstPerson／World 音量基準，新增 Music 分組。100% 等於原基準、0% 為 -80 dB；草稿預聽，放棄還原。現有玩法音效沿 GameplayAudioService 路由；音樂分組已可控，未新增背景音樂曲目。
- 畫質沿 `FusionMenuGraphicsSettings`，確認後同步原 PlayerPrefs；解析度與全螢幕先試用 15 秒。Editor 驗證不改桌面解析度，實際顯示模式切換仍須 Standalone 驗收。連線沿 MenuConfig 的原區域順序、MaxPlayerCount 與 MachineId／AvailableAppVersions，不重編房間代碼。
- `MenuConnection.LeaveAndSaveAsync`：Host 先以 `GameLogic.TryWriteHostExperienceToSave` 更新既有 ActiveSave，再 `GameSaveRuntimeContext.WriteActiveSave`；成功才走既有 DisconnectAsync。失敗拋回設定彈窗保留房間；Client 跳過寫檔，只關閉自己連線。
- `PlayerSettingsInstaller.Install` 是顯式一次性 Editor 配置工具，已執行；有既存配置或 dirty 主選單時拒絕重複覆寫。未移動／改名既有序列化類型。新增 NetInput 欄位後，Host／Client 應使用同一版程式。
