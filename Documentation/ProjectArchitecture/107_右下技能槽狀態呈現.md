## 1. 使用者定案與責任

2026-10-18 使用者確認套用右下技能 UI，保留原本技能規則，並授權同步關鍵詞與文件。沿用既有 StageHUD／SafeHouse 的 LocalPlayerBattleAbilityHUD、圖示、槽位與改鍵提示，不另建施放、傷害、移動、輸入或冷卻系統。

| 狀態 | 正式呈現 |
|---|---|
| 冷卻 | 整個技能格覆蓋深色半透明遮罩，十二點起順時針退去。白色粗體秒數置中、不加數字底板，數值向上取整；到期同時移除。 |
| 冷卻完成 | 觀察到同一技能由冷卻轉為可用才短促亮一次，預設 0.32 秒。不因初始化、換裝、切換觀戰或重新顯示補播。完成時仍不可用就不閃，解除限制也不延後補播。 |
| 二次施放 | 淡金色期限外框沿四邊順時針退去，圖示保持清楚；能按時顯示「再次施放」，暫不可按則低明度外框＋「待命」。精確秒數仍由原中央時間條顯示。 |
| 生效中 | 青色期限外框；原本可再次按下結束的技能才顯示「再次按下結束」，其他為「效果持續」。不把作用秒數放在冷卻白字位置。 |
| 施放準備 | 原準備時間對應外框與「施放準備」；不提示可按第二次。 |
| 等待補包拾取 | 顯示「等待拾取」，不把世界物件存活時間冒充自身 buff 或冷卻。 |
| 條件不足 | 保留既有資格與 ActionGate，鍵帽／背景降低明度。尚未冷卻也不等同一定可以施放。 |

閃現第一次 E 仍依原規則待命，第二次 E 或逾時才開始冷卻；衝刺中的安全期限不作為 buff。空中緩速與子彈時間再按結束仍走原結算，無改動傷害或時間數值。按鍵標示讀現有玩家設定，沒有硬寫 E 作為唯一按鍵。

## 2. 資料流與網路

既有 Host 計時 → 技能唯讀 HUD 屬性 → AbilitySlotHudSnapshot → LocalPlayerBattleAbilityHUD.States → 方格網格／文字／本機亮光。

- 冷卻統一讀取 TAB 資訊窗同批建立的 `PlayerAbilityRuntime.TryReadPresentation`／`IPlayerAbilityCooldownSource`。原有 Timer／EndTick 決定剩餘秒數，既有同步 `CooldownDuration` 提供完整分母；本次右下技能格不再增加重複同步欄位、不另開計時。
- 鈎索尖刺由共用介面沿原 `CooldownTicksSnapshot` 換算總長。
- 掉落轉移同樣沿 `TryReadPresentation` 選取 TransferCooldown 與它的同步總長；右下 HUD 不自行重建或覆寫掉落計時。
- 晚加入、重連、觀戰切換使用同步總長，不以首次看到的剩餘時間重建。Networked 仍限有效 Runtime／Owner 生命週期。
- `HudCanPress`、`HudCanRecast`、`HudCanEndActive` 是唯讀提示，最終是否施放仍由原 SimulateAbility／OnArmedPress／ActionGate 判定。新增條件或階段時須同步檢查 HUD 查詢，不能由 UI 呼叫施放。
- 本機 UI 讀 LocalPlayerControl 的戰鬥鎖；觀戰不拿自己的輸入鎖偽裝被觀戰者狀態。
- 共用冷卻介面所屬版本需要各連線端使用同版程式；本次不修改存檔格式。

## 3. 掛載與 Inspector

既有 LocalPlayerBattleAbilityHUD 建立技能槽實例時自動補上 `AbilityStateOverlay`／`AbilityStateLabel`，只存在於本機複製出的槽位。原 CooldownShade 保留序列化引用、於實例停用；原 CooldownText 沿用並置中。不重建 StageHUD，不覆寫 Scene／Prefab 的位置、尺寸或圖示。

Inspector 選既有 BattleAbilityHUD 的 LocalPlayerBattleAbilityHUD，在「技能格冷卻與二次操作提示」調整：

| 欄位 | 預設／範圍 | 效果 |
|---|---|---|
| Cooldown Shade Color | 黑色、Alpha 0.65 | 改整格遮罩透明度。 |
| Recast Border Color | 淡金 `(229,206,115,255)` | 二次施放期限外框。 |
| Active Border Color | 青色 `(0.25,1,0.9,1)` | 自身效果持續外框。 |
| Ready Flash Color | 暖白 `(1,0.96,0.75,1)` | 完成亮光與外框。 |
| Ready Flash Seconds | 0.32，0～1 秒 | 0 停用亮光；不更動冷卻。 |
| State Border Width | 3，1～8 參考像素 | 隨既有 HUD 等比縮放；不改格子尺寸。 |

仍使用專案原圖與文字字型。狀態短字置於技能格上方，按鍵仍保留原位置。未提供第二段專用圖示時不重畫或替換原圖。

## 4. 驗證與邊界

聚焦驗證涵蓋：完整分母、順時針幾何、二次施放／提前結束語意、冷卻完成僅一次、切換來源／隱藏／阻擋後不補播。Editor 編譯、完整回歸、離屏預覽與受控多人證據集中於 [驗證紀錄](Validation/AbilitySlotStates/README.md)。自然遊玩與獨立 Build 不以離屏圖或同 Editor 測試替代。
