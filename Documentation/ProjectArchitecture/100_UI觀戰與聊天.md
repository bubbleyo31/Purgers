# UI、觀戰與聊天架構

> 最後核對：2026-09-14  
> 相關文件：`20_玩家核心移動與狀態.md`、`50_武器瞄準與射擊.md`、`60_傷害生命死亡與回饋.md`

## 本地 UI 原則

- HUD 只綁定本機 `Input Authority` 的 Player。
- UI 讀取 Networked 結果，但不直接決定傷害、彈藥或生命。
- 有變動才刷新文字／Slider／Sprite，避免每幀重建 UI。
- 職業擴充走資料來源介面，不在 HUD 中無限制追加類型硬判斷。

## 玩家 HUD

| 程式 | 職責 |
|---|---|
| `LocalPlayerHealthSlider.cs` | 綁定本機 `PlayerHealth`；生命變動才更新 Slider |
| `LocalPlayerSpeedSlider.cs` | 讀取本機 `PlayerMovement` 速度；以 Inspector 最大值正規化並封頂 |
| `LocalPlayerGrappleAimIndicator.cs` | 瞄準合法鈎索點時顯示 UI；區分一般 Grapple 與 Enemy／HitMask 互動指示物 |
| `LocalPlayerWeaponHUD.cs` | 依職業／目前武器切換圖片、數值文字與低彈提醒物件 |
| `IPlayerWeaponHUDSource.cs` | 武器 HUD 資料來源介面與數值模式 |
| `AttackRifleWeaponHUDSource.cs` | 提供步槍目前彈匣／備用彈藥、無限符號與低彈判斷 |
| `SupportSMGWeaponHUDSource.cs` | 提供 SMG 彈匣／備用彈藥、特殊無限模式與低彈判斷 |
| `TankComboWeaponHUDSource.cs` | 提供 Tank 目前 Combo／最高 Combo；保留未來 Tank 換彈提醒入口但目前無觸發條件 |
| `FirstPersonHitMarker.cs` | 顯示一般命中、暴頭、擊殺回饋 |
| `TextFlasher.cs` | 通用文字閃爍效果 |

## 移動視覺

| 程式 | 職責 |
|---|---|
| `FirstPersonMovementEffects.cs` | 一般第一人稱高速與移動視覺效果 |
| `FirstPersonSlideReadySpeedLines.cs` | 獨立的「目前速度已可滑鏟」速度線，不和一般 Movement Effects 共用門檻或物件 |
| `GrappleFovEffect.cs` | 依鈎索／GrappleAirborne 狀態向 `FirstPersonFovManager` 提交 FOV Request |
| `FirstPersonFovManager.cs` | 多來源 FOV Request 仲裁，分相機 Channel 與 Modifier Mode |

## 觀戰

| 程式 | 職責 |
|---|---|
| `LocalPlayerSpectatorController.cs` | 本機玩家死亡後等待 1 秒，改由相機跟隨其他存活玩家；重生時回到自己的 Local View |
| `CameraFollow.cs` | 相機跟隨目標與觀戰切換所需的基礎跟隨功能 |

目前觀戰功能是基礎版本；尚未文件化玩家手動切換目標、觀戰 UI 或全員死亡結算，未來新增時不要塞進 `PlayerHealth`。

## 聊天／系統訊息

```text
玩家加入
→ GameLogic / NetworkChatSystem
→ LocalChatMessage
→ LocalChatPanel
```

| 程式 | 職責 |
|---|---|
| `NetworkChatSystem.cs` | 網路聊天／系統訊息入口；目前主要廣播「玩家名字加入了遊戲」，保留未來文字輸入空間 |
| `LocalChatPanel.cs` | 本地顯示訊息列、訊息生命期與視覺更新 |

目前沒有玩家打字與輸入框行為。未來新增時，文字驗證、長度限制、頻率限制與 RPC 權限應放在 Network Chat 層，而不是 Local Panel。
