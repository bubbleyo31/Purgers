## 本地 UI 原則

- HUD 只綁定本機 `Input Authority` 的 Player。
- UI 讀取 Networked 結果，但不直接決定傷害、彈藥或生命。
- 有變動才刷新文字／Slider／Sprite，避免每幀重建 UI。
- 職業擴充走資料來源介面，不在 HUD 中無限制追加類型硬判斷。

## 觀戰

| 程式 | 職責 |
|---|---|
| `LocalPlayerSpectatorController.cs` | 本機玩家死亡後等待 1 秒，改由相機跟隨其他存活玩家；重生時回到自己的 Local View |
| `CameraFollow.cs` | 相機跟隨目標與觀戰切換所需的基礎跟隨功能 |

目前觀戰功能是基礎版本；尚未文件化玩家手動切換目標、觀戰 UI 或全員死亡結算，未來新增時不要塞進 `PlayerHealth`。

## 聊天／系統訊息

```text
玩家加入
→ GameLogic / NetworkChatSystem
→ LocalChatMessage
→ LocalChatPanel
```

| 程式 | 職責 |
|---|---|
| `NetworkChatSystem.cs` | 網路聊天／系統訊息入口；目前主要廣播「玩家名字加入了遊戲」，保留未來文字輸入空間 |
| `LocalChatPanel.cs` | 本地顯示訊息列、訊息生命期與視覺更新 |

目前沒有玩家打字與輸入框行為。未來新增時，文字驗證、長度限制、頻率限制與 RPC 權限應放在 Network Chat 層，而不是 Local Panel。
