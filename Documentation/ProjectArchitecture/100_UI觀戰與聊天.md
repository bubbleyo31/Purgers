## 本地 UI 原則

- HUD 只綁定本機 `Input Authority` 的 Player。
- UI 讀取 Networked 結果，但不直接決定傷害、彈藥或生命。
- 有變動才刷新文字／Slider／Sprite，避免每幀重建 UI。
- 職業擴充走資料來源介面，不在 HUD 中無限制追加類型硬判斷。

- 死亡後仍沿用原 `spectatorActivationDelay`；目前設定 1 秒。觀戰改讀被觀戰者的 CamTarget 位置與同步 Pitch／Yaw，取消第三人稱後方距離、肩偏移及額外平滑。舊序列化參數保留並隱藏，不修改 Scene／Prefab。
- `CameraFollow.SetWorldPose(owner, position, rotation)` 保存世界姿態快照；owner 只供清除時辨識。即使觀戰控制器掛在 CameraRig 子階層，也不再發生父物件跟隨子物件的位移回授。SetTarget 恢復一般跟隨，舊 owner 的 ClearTarget 不會清除新玩家。
- `TryGetViewedPlayerObject(runner, out object)` 是純本機、只讀呈現路由：有效本機玩家優先；本機角色不存在時才選擇同 Runner 的有效觀戰目標。不得用 IsViewedObject 取代 Gameplay／RPC 權限檢查。
- ViewModel 以 `SetObservedTarget` 讀取被觀戰者武器、動畫、換彈、ADS 與槍口火焰；觀戰不寫入或清除遠端 Gameplay Weapon 的 Tracer Muzzle。既有 FOV 仲裁、武器動態、速度效果與鉤索視覺沿用被觀戰者來源。
- 只在觀戰端將 TeammateVisualAnchor.bodyRenderers 改為 ShadowsOnly，離開／換目標還原各 Renderer 原值。隊友 HUD 不畫被觀戰者自己的名條與輪廓。
- 生命／護盾、彈藥／換彈、動能、Q／E 技能與時間條、經驗等級、準心、小地圖均讀被觀戰者。地圖探索改讀其同步探索快照；不改探索寫入。觀戰者按 Q／E 不使 HUD 假裝隊友按鍵，ALT 不開啟或領取隊友獎勵。
- 目標死亡／離線時釋放來源，改找其他存活隊友；無目標則隱藏舊 HUD／模型並保留最後鏡頭位置。自己重生時還原本機呈現。

### 設定與手動驗收

1. 沿用 `_Menu/CameraRig/CameraEffectsRoot/LocalSpectatorCameraController`、既有 CameraFollow 與 WorldCamera／WeaponCamera Stack，不新增或移動相機。
2. 玩家 Prefab 的 TeammateVisualAnchor.bodyRenderers 必須只包含第三人稱身體，勿包含第一人稱手／武器；現有 KCC_Player 已有該引用。本輪不改資產。
3. 唯一仍有效的觀戰時間參數為控制器的 Spectator Activation Delay，單位秒，有效範圍 >= 0；0 表示角色物件消失後立即觀戰。第三人稱距離／肩偏移／平滑／碰撞舊值目前不生效。
4. 兩個獨立程序進入同關，讓 A 死亡、B 存活；確認 A 顯示 B 的上下視角、手／武器、血量彈數。B 開鏡／射擊／換彈／換武器時觀察動畫及 HUD；A 操作不得影響 B。
5. B 死亡／離線時不得留下舊手部、身體遮鏡或 HUD；A 重生後必須還原自己資料與 B 的第三人稱身體。
6. 多人網路傳輸的是角色與武器狀態，不是隊友螢幕串流；延遲、Input Authority 專用命中／受傷／回血 RPC、鏡頭震動與私有 UI 不保證逐幀相同。獨立程序與最終自然畫面驗收見驗證紀錄。

本輪只實作觀戰切換；倒地、救援、30 秒期限、復起仇恨及撤離名單的新規則尚未實作，原自動重生仍保留。

- 沿用死亡後 1 秒進入第一人稱觀戰。倒地者仍保持自己的視角；健康及倒地隊友均為候選，正式死亡、離線、尚未 Spawn 或不同 Runner 排除。
- 名單依既有隊友 ColorSlot 排序，PlayerRef 作同序回退。Q 上一位、E 下一位，兩端循環；一位保持目標，零位清除相機與舊 HUD／ViewModel 綁定並顯示等待。
- 兩鍵同時按不切換；長按不連續切換。觀戰開始、選單關閉、控制鎖解除後須放開 Q／E 才接受新按下。固定鍵不讀玩家技能改鍵。InputManager 在觀戰時清除 Gameplay 意圖並封鎖仍按住的輸入，避免復活後觸發技能。
- 新玩家加入、目前目標倒地或復起，不搶換視角。目標正式死亡或無效時接續原位置的下一位；切換只改本機相機、身體顯示、ViewModel 與只讀 HUD，不授予遠端操作權。

- ESC 選單與 AllInput／Gameplay 控制鎖擋住切換；全滅轉場隱藏資訊列並停止觀戰切換，復活退出觀戰。
