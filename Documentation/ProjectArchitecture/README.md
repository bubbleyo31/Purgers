## 使用方式

新對話可先提供 `00_CHATGPT快速讀取.md`，再依當次任務補上相應模組文件。若 ChatGPT 能直接讀取專案檔案，仍應在修改前核對實際 C#，不可把文件當成永遠正確的程式快照。

每次架構更動完成後，依 `120_文件維護規則.md` 同步修正文件。只有數值調整且完全不改職責、介面或資料流時，不必重寫整份架構。
