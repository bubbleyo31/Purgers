## 已確認外觀與範圍

使用者確認橄欖綠角色面罩，並接受參考 Lethal Company 的內側視角：上方中央淺弧、略微柔化的深色橡膠內襯、少量橄欖綠內殼、極薄下緣與側緣。中央不染色、不模糊、不扭曲；無鼻樑、濾罐、污漬或額外玩法。使用者明確授權可調厚度／透明度並直接配置 Unity。

以原生 UGUI 周邊曲面重現已確認概念；生成圖只作外觀參考，不把含有 HUD 的預覽當作遊戲貼圖。現有 HUD 座標、縮放與資料來源不變。

## 責任與生命週期

- `GoggleRimGraphic`：一個 MaskableGraphic，僅在四周建立漸層曲面，中央沒有三角形。使用既有 UI 預設材質，無額外貼圖、shader、後處理、Camera 或 Renderer Feature；不改 FOV。
- `LocalFirstPersonGoggles`：純本機 MonoBehaviour；沿用 `LocalPlayerSpectatorController.TryGetViewedPlayerObject` 路由。單一有效且 ProvideInput 的 Runner 可自動綁定；多個候選時隱藏，不能任意挑一個。`BindRunner` 可明確指定多 Peer 的觀看端。
- 取得有效 NetworkObject，且 PlayerHealth 的既有 `IsRescueReady` 成立後，才讀 `IsDead`。健康／倒地玩家顯示；死亡無有效觀看目標、場景載入、斷線或尚未生成時隱藏；有合法第一人稱觀戰目標時跟隨既有路由。
- 不送 RPC、不寫 Networked、不讀玩家輸入、不改移動、碰撞、傷害或相機位置。
- Graphic 永遠不接收 Raycast；CanvasGroup 不互動也不阻擋 Raycast，沒有 GraphicRaycaster。

## 正式配置與調整

已配置於 `_Menu / GameplayHUD Canvas / PlayerHUDCanvas / FirstPersonGoggles`，Prefab 為 `Assets/Prefabs/UI/FirstPersonGoggles.prefab`。沿用常駐玩家 HUD 的生命週期，不在 Game、SafeHouse 或每個玩家身上重複放置。

護目鏡使用全畫面 Stretch，獨立子 Canvas 的 Override Sorting 開啟、Order = -10，低於目前玩家 HUD 的 0、StageHUD 的 100 及轉場黑幕。控制器在啟用／父層變動時只固定自己的 Canvas 排序，不調整既有 UI。護目鏡不放在 1920×1080 ReferenceFrame 內，因此超寬螢幕仍貼實際視窗外緣；曲面厚度按可用寬高的較小比例縮放。

選取上述物件，調整 **Goggle Rim Graphic**：

| Inspector 欄位 | 預設 | 範圍與作用 |
|---|---:|---|
| Thickness | 1 | 0～2；0 隱藏。建議 0.6～1.2，只增減邊緣深度，不縮放中央或 UI。2 是可測的上限，不是建議常態值。 |
| Opacity | 0.94 | 0～1；0 完全透明、1 完全不透明。只改曲面 Alpha。 |
| Edge Softness | 5 | 0～12，1080 高度參考像素；只柔化內緣，隨厚度倍率縮放。 |
| Shell Color | 深橄欖綠 | 調內殼的少量表面；不套用全畫面色調。 |
| Rubber Color | 近黑色 | 調橡膠內襯。色票 Alpha 不參與，使用 Opacity。 |

**Local First Person Goggles** 的 `Preview In Editor` 預設關閉；勾選可在編輯模式預覽。Play Mode 一律由有效玩家判定。若要永久改值，請在退出 Play Mode 後調整 Scene Instance 或 Prefab；不要將執行中的暫時參數誤當作已保存。

不透明度過低會減弱配戴感；厚度過高會增加世界畫面的遮擋，即使 HUD 排序在上方仍應保留目前預設的安全留白。未增加抖動、呼吸、髒污或 ADS 變化。

## 成本與工具

本次前的護目鏡成本為零。新增單一 Graphic、單一子 Canvas；正常幾何 1,568 頂點／2,688 三角形（1,344 個曲面四邊格，各拆兩三角形，無 ngon），無新增材質檔或貼圖。這是 UI 生成幾何，不是 DCC／FBX 模型；無 FBX 匯入或動畫 round-trip。參數／尺寸變更時重建，穩定狀態不每幀重建網格。不宣稱已量測 draw call、GPU 成本或目標平台效能。

`Tools > Purgers > UI > Create And Wire First Person Goggles` 僅在乾淨且已開啟的 _Menu 工作；已存在時保留人工值，不重套其他 HUD。接線前保留既有元件序列化快照，核對沒有改動再保存。
