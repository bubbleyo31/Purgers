## 定案規則

- 新獨立能力 ID 為 `grapple.spike`，分類為 `GrappleHit`，可跨職業裝備。它使用命中槽，但由玩家周圍接觸觸發，不要求鉤頭命中敵人、不按 E。
- 普通 Attached 且正在拉動玩家自己時待命；Support 拉別人的 Tether 不合格。斷繩後 Release Momentum 可獨立開啟，預設關閉。PreFire、Shooting、一般跳躍／走路不合格。
- 球形範圍跟隨玩家、包覆全身；沿連續有效 Tick 的前後球心做掃掠，避免高速穿過敵人漏傷。重新附著、冷卻結束與跨過無效 Tick 不補掃無效期間的路徑。
- 待命只偵測，沒有尖刺視覺、不計效果時間、不進冷卻。首次有效命中當下出傷並開始效果期限。
- 效果期預設 3 秒。斷繩隱藏且預設停止出傷，但計時繼續；期限內再次鈎索可恢復。後續命中不刷新期限。
- 效果期結束後才開始 3 秒冷卻；到期仍在有效鈎索狀態就自動待命，下一次命中才開始新效果。
- 每名敵人各自至少相隔 0.5 秒才可再次受傷／擊退。多個 Collider 視為同一個 NetworkId；不同敵人及不同玩家獨立。間隔以 Tick 向上取整，不因重新鈎索或輪次切換清除。
- 每次出傷取樣當下 `PlayerGrappleMomentumEnergy.DamageMultiplier` 一次，保留原 BaseDamage。只讀增傷量條，不扣能量、不清除滿值保持、不改自然衰退。
- 傷害成功後從接觸時玩家球心向敵人水平向外微擊退；沿用既有敵人擊退免疫、Pull／Gather 仲裁。無額外撞牆傷害、無額外暈眩。擊退本身沿用受控移動，因此會中斷敵人當前攻擊。
- 只傷同 Runner 的存活 EnemyActor，不傷玩家；沿用共用世界遮擋判斷，其他角色不充當牆。
- 首次命中才亮起，效果期限內且符合鈎索條件才顯示。冷卻、死亡、卸下、失去職業資格時隱藏；職業不允許／死亡沿能力生命週期提前結束並進冷卻，普通斷繩不提前結束。
- 子彈時間沿用既有 Deferred 契約：已受理的延後傷害也記錄本次接觸及間隔，避免凍結期間每 Tick 重複送件；倍率在送件時快照，正式傷害回饋由原延後結算發出。完全格擋／拒絕且非 Deferred 不啟動效果。

## 責任與網路

`Player → PlayerAbilityRuntimeManager → PlayerAbilityRuntime → PlayerGrappleSpikeAbility.SimulateAbility`。
Host／State Authority 查詢自己的 Runner PhysicsScene、讀動能倍率、呼叫 DamageReceiverUtility，再交給 PlayerCombatFeedbackRelay 與 EnemyStateController.TryBeginAbilityKnockback。

技能使用獨立 Network Runtime；EffectEndTick、CooldownEndTick、效果時長快照、冷卻 Tick 快照、ContactEligible 與命中序號同步。每目標命中表只由 Host 保存。各觀察端只讀有效狀態，建立／顯示本機視覺；LateUpdate 不查敵人、不送傷害。

不新增玩家傷害、移動、輸入或鈎索路由系統。不改既有三項鉤頭命中 Router；尖刺不爭奪繩索控制權，因此不加入 GrappleHitRopeAuthority。裝備容量仍由 Slot Layout 管理，重複裝備同一 Definition 被禁止。

IPlayerAbilityHudState 提供原 HUD 的效果剩餘與冷卻秒數；效果時間條即使斷繩仍繼續顯示倒數，世界尖刺可隱藏。沿用中央時間條的既有優先選擇，不建立第二個 HUD 計時器。

## 資產與手動接線

Editor 選單：`Tools → Player Ability → 建立鈎索尖刺資產（僅補缺）`。
工具只建立缺少的獨立資產，不覆寫既有人工數值，不保存 Scene，不改玩家 Prefab、預設 Loadout 或獎勵池。

- Definition：`Assets/_Project_Assets/Data/PlayerAbility/GrappleSpike/GrappleSpike.asset`
- Runtime：`Assets/Prefabs/AbilityRuntime/GrappleSpikeRuntime.prefab`
- 視覺：`Assets/Prefabs/AbilityRuntime/GrappleSpikeVisual.prefab`
- 範例 Loadout：`Assets/_Project_Assets/Data/PlayerAbility/GrappleSpike/GrappleSpikeLoadout.asset`；由既有預設 Loadout 保留非 GrappleHit 項目，將命中槽替換為尖刺。

手動接線：
1. 在既有 Loadout 的 Equipped Abilities，以 GrappleSpike Definition 替換要更換的 GrappleHit 能力；或在測試玩家 PlayerAbilityRuntimeManager 的 Starting Loadout 指向上述範例。
2. 不把技能元件直接加在 KCC_Player；正式 Loadout 會生成獨立 Runtime。
3. 在 Runtime Prefab 調整表列數值與 Layer。選中技能可看球形 Gizmo；Play Mode 下球心隨 Owner。
4. Play Mode 未撞到敵人時尖刺保持隱藏；撞到後觀察 3 秒效果與 3 秒冷卻，以及同目標半秒間隔。
5. 斷繩再鈎索，確認期限不刷新；切換 Include Release Momentum 測試兩種狀態。
6. 多人各端使用同版本資產及 Fusion Prefab Table；自然 Host／Client、高速貼牆與最終視覺仍需人工驗收。

## 佔位視覺資源預算

基線：此新技能原先沒有視覺資產，新增成本由零起算。目標預算為每份本機視覺 1 Mesh／1 Material／0 貼圖、≤200 三角形。
實際 32 支尖刺；每支 4 個三角側面與 1 個四邊底蓋，匯出為三角索引：概念拓樸 128 triangles + 32 quads、0 ngons；Unity Mesh 為 192 triangles、160 vertices、1 Mesh、1 Material、0 貼圖。尖端使用必要三角收束，沒有細分、物理元件或額外網路物件。
這是 Editor 生成的 Mesh 資產，不含 FBX、骨架或動畫，因此無 DCC／FBX round-trip；尚未量測實際 draw calls、GPU 效能或第一人稱觀感。
