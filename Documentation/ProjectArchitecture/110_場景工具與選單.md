# 場景、工具、選單與其他輔助程式

> 最後核對：2026-09-14  
> 相關文件：`10_網路連線與輸入.md`

## 場景與選單

| 程式 | 職責 |
|---|---|
| `GameLogic.cs` | 遊戲場景玩家生成、Spawn Point、死亡重生、職業保存與離線清理 |
| `MenuConnection.cs` | 選單連線資料與操作入口 |
| `MenuConnectionBehaviour.cs` | 連線流程的 Unity／Fusion Behaviour 包裝 |
| `MenuUIController.cs` | 選單畫面、按鈕與連線狀態 UI |

## 關卡與編輯工具

| 程式 | 職責 |
|---|---|
| `CourseGenerator.cs` | 關卡／路線生成工具的 Runtime 資料與執行入口 |
| `CourseGeneratorEditor.cs` | `CourseGenerator` 的自訂 Inspector／Editor 操作；只存在 Editor 組件 |
| `ShowNavmesh.cs` | 顯示 NavMesh 的開發輔助工具 |
| `AutoAddMeshCollider.cs` | 自動替目標 Mesh 補上 MeshCollider 的場景建置工具 |

## 測試與展示元件

| 程式 | 職責 |
|---|---|
| `NetworkPingPongMover.cs` | 網路物件往返移動測試／場景機關範例 |
| `EnemyPatrolAreaTestSpawner.cs` | F4 Enemy 測試生成；詳細見 `91_敵人攻擊表現與生成.md` |

## 相機通用元件

| 程式 | 職責 |
|---|---|
| `CameraFollow.cs` | 相機跟隨目標；被 Local View、觀戰與 Grapple Visual 使用 |
| `FirstPersonFovManager.cs` | 第一人稱多來源 FOV 修改仲裁 |
| `FirstPersonHitCameraShake.cs` | 命中結果相機震動 |

## 維護原則

- Editor 程式維持在 `Assets/Scripts/Editor` 或 Editor-only Assembly，避免進 Build。
- Debug Gizmo 不可在 Runtime 每幀產生 GC 或更改 AI 狀態。
- 測試生成與測試移動物件不能被正式波次、任務或存檔系統依賴。
- `GameLogic` 若繼續擴張到回合、Encounter、計分與結算，應拆成各自 Controller，不要變成全域 God Object。
