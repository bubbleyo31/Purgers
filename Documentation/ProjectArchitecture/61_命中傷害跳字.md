# 命中傷害跳字

最後核對日期：2026-10-11（本功能局部核對）。
核對來源：PlayerCombatFeedbackRelay、DamageNumberSettings、DamageNumberRules、LocalPlayerDamageNumbers、DamageNumberRuntimeVerification，以及本次使用者確認。
相關文件：[傷害與回饋](60_傷害生命死亡與回饋.md)、[本機 HUD](100_UI觀戰與聊天.md)、[驗證紀錄](Validation/DamageNumbers/README.md)。

## 1. 已確認需求與本版行為

- 只顯示自己對敵人造成的已結算傷害。沿用 Host／State Authority 的 DamageResult → PlayerCombatFeedbackRelay → Input Authority LocalHitConfirmed；不比較血量反推、不在 Client 重新計算傷害。
- 使用權威 request.HitPoint 作為世界位置快照，字體大小依視口高度縮放，不依距離或敵人體型縮小；不把數字固定在敵人頭頂。範圍／近戰使用各傷害來源現有的 HitPoint，不假造新的表面命中。
- 命中後位置不追蹤敵人；每幀投影同一世界點，再加小幅螢幕上飄。移動相機時仍與原世界位置對齊。合併保留第一筆位置；敵人死亡／Despawn 不會提前刪除已生成的數字。
- 隔牆仍顯示，無物理遮擋查詢、敵人輪廓或透視模型。僅影響已被權威確認的回饋，不讓武器穿牆造成傷害。
- 實際命中點必須在世界相機視口內且在 nearClipPlane 前方；畫面外事件不進池，已顯示的點離開畫面即結束，不做邊緣箭頭、轉回不重播。巨型敵人以實際受擊部位解決頭頂出框問題；目前沒有「命中點已出框但其他身體仍可見」的自動定位備援。
- 頭部樣式依 HitZone == Head；技能把身體傷害強制當成暴頭時，不會被顯示為物理頭部命中。沿用原本命中音效／HitMarker 的 IsHeadshot 行為，不改其規則。
- 顯示 AppliedDamage 實際扣血量，含剩餘 HP 上限：剩 10 HP 受到 100 請求傷害顯示 10。顯示一位小數（整數省略小數）；正值小於 0.1 顯示 <0.1。這是本版沿用既有回饋的數值政策。

## 2. 合併與識別

一般攻擊包含 Bullet／Melee／Explosion／Ability 等非 DamageOverTime 類型，預設每次獨立跳。持續傷害僅識別既有 DamageType.DamageOverTime，預設合併；不把快速連射猜成持續傷害。目前未替其他武器或 E 技能改傷害分類，也未新增燃燒／中毒 Gameplay。

| Individual Hits | Merge Continuous Damage | 一般攻擊 | 持續傷害 |
|---|---|---|---|
| 開 | 開（預設） | 逐次 | 合併 |
| 關 | 開 | 合併 | 合併 |
| 開 | 關 | 逐次 | 逐次 |
| 關 | 關 | 合併 | 逐次 |

兩個開關是「選擇逐次或合併」，不是單獨隱藏該類傷害；總開關 Show Numbers 才是隱藏全部。

合併必須同 TargetKey、SourceKey、DamageType、FeedbackId 與頭部樣式。TargetKey／SourceKey 為 Host 物件 InstanceID 的不透明整數快照，僅在這個 Relay／短暫時間窗內比較；Client 不拿它呼叫 FindObject、不依賴目標仍然存在，也不作存檔／跨連線識別。每次換綁清空。

合併窗由第一筆開始，不刷新生命期，也不移動到新命中點。超過合併窗另開新筆；最大顯示數滿額回收最舊一筆。合併只是本地 UI，不減少現有 RPC 的每筆傳送數量。

## 3. 資產與手動接線

已建立：

- Prefab：`Assets/Prefabs/UI/DamageNumbers.prefab`。
- 共用設定：`Assets/_Project_Assets/UI/BattleHUD/DamageNumberV1.asset`。
- 數字字型沿用 `Assets/_Project_Assets/UI/BattleHUD/Fonts/MuseoModerno-Bold SDF.asset`。
- Prefab 本身只有 RectTransform 與 LocalPlayerDamageNumbers，設定／Visual Root 已接好；沒有 NetworkObject、Collider、Rigidbody 或 GraphicRaycaster。

**尚未放入正式 Scene／玩家 Prefab。** 建議手動流程：

1. Edit Mode 開啟 `_Menu`，找到既有 `GameplayHUD Canvas/PlayerHUDCanvas`（與 DamageIndicators 同層）。
2. 把 `DamageNumbers.prefab` 拖成其子物件，確認此分支為 Screen Space Overlay 或 Screen Space Camera；不要放到 World Space Canvas、Mask／RectMask2D 內，也不要在 StageHUD 再放第二份。
3. RectTransform 使用全幅 Stretch，四邊偏移 0，Scale 1。保留既有 HUD 排版。
4. Local Player Damage Numbers：Settings 指向 DamageNumberV1；Visual Root 指向自身；World Camera 指定遊戲世界相機，不能選 ViewModel 相機。
5. 一般單 Runner 可讓 Runner 留空；只在唯一有效本機 Runner 時自動認領。多 Runner 必須由建立者呼叫 Configure(settings, runner, worldCamera) 各自指定，不能共用另一位玩家的 UI。
6. 手動保存你確認的 Scene／Prefab 修改。Play Mode 打身體與頭部，觀察白色普通字／金色放大字。

Runtime 依需要建立上限 128 的 TMP 顯示槽（設定預設只用 64），停用／換綁／斷線清空；文字不接收滑鼠事件。材質是各跳字槽的本地副本，移除元件時釋放，沒有改原字型材質。

## 4. Inspector 調整手冊

統一位置：選取 `DamageNumberV1.asset` → Inspector。除引用外均可於 Play Mode 試調；ScriptableObject 調整可能保存，試驗前可複製資產。改動僅影響本機 UI，不改 Host 的傷害或存檔。

| 欄位 | 資產預設 | 有效範圍／作用 |
|---|---|---|
| Show Numbers | true | false 清除並停止跳字，其他命中回饋仍保留 |
| Individual Hits | true | 一般攻擊逐次／合併切換 |
| Merge Continuous Damage | true | 持續傷害合併／逐次切換 |
| Merge Window | 0.2 秒 | 0.02～1；首次命中開始的固定窗，生命期較短時先到期 |
| Maximum Numbers | 64 | 1～128；滿額回收最舊筆，降低即清除超額槽 |
| Font | MuseoModerno-Bold SDF | TMP 字型；留空退回 TMP 專案預設；若兩者皆無則不呈現 |
| Font Size | 30 | 8～96，1080 視口高度基準，不受距離／FOV 改變大小 |
| Normal Color | 白 #FFFFFFFF | 一般命中 RGBA |
| Head Color | 金黃 #FFD34DFF | 實際 Head 命中 RGBA，可自行替換 |
| Head Scale | 1.35 | 1～3；1 不放大，正常穩定字級為 30 × 1.35 = 40.5 |
| Outline Color | 近黑 RGBA(0.04,0.04,0.04,1) | TMP SDF 描邊色 |
| Outline Width | 0.18 | 0～0.4；0 關閉，需字型材質支援 SDF 描邊 |
| Hit Offset | (18,18) | 1080 基準像素，右／上偏移；可為負值 |
| Rise Distance | 32 | 0～80，整段生命期向上移動的基準像素；0 固定 |
| Lifetime | 0.8 秒 | 0.1～3；從首次出現計算，合併不延長 |
| Hold Fraction | 0.45 | 0～0.9；預設前 0.36 秒維持，再線性淡出 |
| Pop Scale | 1.12 | 1～1.5；前 0.12 秒回到 1，與 Head Scale 相乘 |
| Stack Spacing | 14 | 0～40 基準像素；同敵人最多三個垂直錯開位置，0 關閉 |

畫面縮放 = 相機 pixelHeight / 1080，並由 ScreenPointToLocalPointInRectangle 換算實際 UI 容器比例，兼容 BattleHudReferenceFrame 的巢狀縮放。只在有效命中點在視口內時，輕微夾住文字邊界，避免文字被螢幕邊緣截斷。

試調例：想更醒目，可把 Head Scale 改 1.5 或 Head Color 改橘紅；想更穩定，把 Rise Distance 改 16、Stack Spacing 改 8；想比較連射累積感，關閉 Individual Hits，但不必改 Merge Continuous Damage。這些是調整例，不是已驗收的新預設。
