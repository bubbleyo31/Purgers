## 規則與狀態

使用者確認的方向：細線瞄準 → 中線蓄力／鎖定 → 粗光束、亮核與粒子瞬間發射 → 只縮粗細，長度不變，最後完全隱藏。敵人追蹤淺色、鎖定深色。兩種敵人及玩家貫穿砲皆使用四階段。美術數值為可迭代初版，不代表使用者已驗收遊戲內觀感。

敵人沿原 Combat Decision 的 Tracking／LockedDelay／Recovery；中線就是原有真正鎖定期。玩家沿 PlayerActiveAbilityBase 的 Casting／PhaseTimer／PhaseDurationSeconds，把同一前搖分成細線／中線；兩段均可移動、轉向，正式 Activate 才取最新位置與準星，預告不能提前命中或鎖死方向。

正式傷害仍只由 Host／State Authority 執行。共用 BeamPresentationRuntime 只建立本機 LineRenderer、ParticleSystem 並呼叫既有音效服務，不能變更權威階段。沒有新增攻擊、傷害或音訊池。

### 粒子

Presentation → Particles：
- Enabled：總開關。
- Muzzle Count／Beam Count／End Count：18／48／22；限制各 0～128、0～256、0～128，內建總池上限 512。
- Lifetime：0.18 s；Size：0.045 m；Speed：2.5；Radius：0.12 m；Color：HDR (.2,2,1.65,1)。
- Prefab：可選純視覺 ParticleSystem，空白使用內建火花；不可有 Collider、Rigidbody、NetworkObject。仍由本接口控制一次性 Emit、世界座標、不循環、粒子上限及消退模組。自訂子粒子系統的成本需自行檢查。
- Material：BeamSparks.mat，柔邊圓點 Shader。發射口、沿線、終點發射火花；「終點」是原視覺終點，不另宣稱一定命中實體。敵人原 Visual Obstacle Mask 設定保留。
- 每次正式發射只爆發一次；不持續每幀生成，不影響 Unity 全域 Random。取消、停用、Despawn 清除持有粒子；自然結束由 Lifetime 淡出。

## 四個聲音接口

Presentation → Audio 含 Prepare、Aim、Charge、Fire，皆為 BeamAudioSlot：
- Cue：GameplayAudioCue；目前三個正式 Prefab 均留空，**已完成接口但尚無正式音檔**。
- Clip Index：0～255，預設 0；Pitch：0.01～3，預設 1；Volume：0～1，預設 1。
- Cue 內設定音檔變體、音量、Mixer、3D 衰減；建議 World Spatial Blend = 1，Doppler = 0，沿既有 World Mixer。
- 這條路徑由已同步權威階段／序號驅動各端播放，使用固定 Clip Index／Pitch，各端不再隨機。因此 Cue Network ID 可為 0，不需另加 Catalog 或音效 RPC；Network Delivery 在此不使用。其他武器／鈎索 RPC 契約不變。

| 接口 | 時機／清理 |
|---|---|
| Prepare | 新攻擊首次可見階段的一次聲；正常與細線開始同時，兩個接口可以只填一個，不額外新增玩法等待 |
| Aim | 進入細線；Loop Aim 預設 true，持續跟隨來源直到換段／取消 |
| Charge | 進入中線；Loop Charge 預設 true，發射／取消即停止 |
| Fire | 觀察到新的正式發射且仍在效果窗口時播放一次 |

關閉 Loop Aim／Loop Charge 後改為該階段一次聲。循環聲沿 GameplayAudioService 的既有 World Loop handle 清理；本次增加 StartWorldLoopWithVolume 入口接受 volumeScale；原 StartWorldLoop 四參數介面維持不變並以音量 1 轉呼叫，保留既有反射呼叫相容性。Prepare／Fire 是短促一次聲，可自然播完。

第一次快照不重播歷史準備／發射／粒子；晚加入可恢復當前線段及該階段循環聲。當網路略過某個短階段，不補播已過期的該段一次聲，避免瞬間堆疊。禁用或斷線後不保留循環 handle。

## 網路與相容性

- 敵人新增 ShotStartPoint／ShotEndPoint／ShotVisualDuration 快照，發射後不再跟槍口移動；原 BeamEndPoint 仍供命中，BeamVisualEndPoint 仍供預告。
- 玩家新增 BeamDuration 快照，既有 BeamStart／BeamEnd／BeamTimer／BeamVisualSequence 不變。預告射線只做本機可見遮擋查詢，穿透敵人、遇牆／隊友停止；實際命中仍由原 Activate 的 Lag Compensation 完成。
- 寬度依 Fusion Object.RenderTime 與既有 TickTimer 終點計算；重新加入不從滿寬重播。
- 原玩家 beamWidth／beamColor 保留序列化為舊資料回退，不再作正式調整入口；既有 fireVfx 插槽仍可取代正式發射視覺，四階段參數控制內建呈現，不接管自訂 VFX 內部動畫。
- 更動了 Networked layout，Host 與 Client 必須使用同版；未更名或移除原序列化類型／欄位。
