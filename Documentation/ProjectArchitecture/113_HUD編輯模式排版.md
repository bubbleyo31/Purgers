## 操作

1. 停止 Play，開啟 `Tools > Purgers > UI > HUD 排版`。
2. 選擇 HUD，按「建立排版草稿」。工具使用正式 Graphic、字體、圖示與固定範例資料，無須玩家或 Runner。
3. 按「在 Scene 檢視」，以 Unity **Rect Tool（T）** 拖動「可拖曳」容器。位置與寬高也可直接在 RectTransform Inspector 輸入。選取後 F 可框選局部，滑鼠滾輪依原生 Scene View 操作縮放。
4. 參照視窗中的即時離屏圖；自己區可切換格檔、0～4 個異常，調整圖示／量條／字級／間距。範例數量、血量、圖示狀態不會保存至玩法。
5. 按「套用版面（可 Undo）」：設定資產立即保存；Scene／Prefab 原物件只寫入 RectTransform 並標記 dirty，依原本流程自行保存 Scene／Prefab。
6. 「關閉草稿」丟棄尚未套用的調整。關閉視窗、重新編譯、離開 Edit Mode、結束 Editor 都會清除草稿。**不要另存預覽場景**；預覽物件為 DontSave，只有「套用版面」會寫回來源。

工具不自動開啟視窗、不聚焦 Scene View。只有使用者點擊「在 Scene 檢視」才框選與切換 2D；背景驗證使用獨立 Preview Scene，沒有這條前景操作。

## 可調整內容與保存位置

| 類型 | 可直接排版 | 保存來源／限制 |
|---|---|---|
| 自己異常／格檔 | 整組 X/Y、異常區寬度；圖示、列間距、格檔字級與量條高度 | `Assets/Resources/Presentation/StatusEffectHud.asset`；X → 新增 `selfHorizontalOffset`、Y → 原 `selfCrosshairOffset`、寬 → `selfWidth`。自己區維持準心下方；高度依可見項目自動收合。 |
| TAB 隊伍窗 | 整窗 X/Y、寬高、等比縮放 | `Assets/Resources/Presentation/TeamInfoPanel.asset`；新增 `windowOffset`，沿原 `windowSize`／`scale`。四列與內部自動排版保留，不支援單列任意拆散。 |
| 敵人血條／異常 | 上下頭頂間距、血條寬高 | `Assets/_Project_Assets/UI/BattleHUD/EnemyHealthBarV1.asset` 的 `padding`／`barSize`；十字為目標投影，仍水平跟隨目標，不能拖成固定螢幕位置。 |
| 隊友名條／異常 | 上下頭頂間距、寬高、名字字級 | `Assets/_Project_Assets/UI/BattleHUD/TeammateDisplayV1.asset` 的 `headPadding`／`nameWidth`／`barHeight`／`nameSize`；異常與名稱仍由可見列數避讓。 |
| 現有 Scene／Prefab HUD | 所選容器 RectTransform（位置、尺寸、錨點、Pivot、縮放） | 直接寫回指定的原物件；不複製預覽子物件。選擇被 Layout Group 控制的子項或 BattleHudReferenceFrame 會拒絕，應改調整外層容器／Layout Group。 |

「現有 Scene／Prefab HUD」使用方式：先在 Scene 或 Prefab 模式選取 UI 容器，再按「使用目前選取的 RectTransform」。例如 `StageHUD.prefab > ReferenceFrame > BattleAbilityHUD > AbilitySlots` 可預覽兩個正式技能槽與冷卻／生效狀態；`BattleAbilityHUD` 可查看其能量環與技能槽整組。既有生命、武器、動能、救援、觀戰等容器可預覽其現有美術，但本工具沒有為每一種狀態注入完整遊戲資料；請選整組容器，原 owner 控制的內部 Graphic 仍可能在遊戲中依數值伸縮。

Prefab 必須先打開 Prefab 模式，不能將 Project 視窗中的 Prefab 資產當作可直接寫入的 RectTransform。已開啟 Prefab 模式時，預覽放在同一 stage 的額外 DontSave root，避免另開場景破壞來源引用；清理只刪除自己的預覽，不關閉使用者的 Prefab stage。

## 責任與相容性

- `HudLayoutWorkspace`：使用者操作入口、預覽生命週期、套用按鈕；僅 Editor 編譯。
- `HudLayoutSession`／`.Samples`：原生 RectTransform 草稿、正式元件示例、來源衝突檢查、白名單版面欄位寫回與 Undo。設定複製品只供預覽，不進 Resources 或 Build。
- `HudLayoutVerification`：同一 Session 的離屏驗圖，不另畫假 UI。
- 原 `StatusEffectListView`／`LocalPlayerGuardHUD` 讀 `selfHorizontalOffset`；`SetCrosshairOffset` 保留 X，施法避讓只沿既有規則改 Y。新欄位預設 0，舊資產位置不變。遊戲中施法條出現仍可能上移整組，預覽的基準位置不是「不允許避讓」的覆寫。
- 原 `LocalTeamInfoPanel.Build` 讀 `windowOffset`；預設零，資料、游標／控制鎖、冷卻與名冊生命週期不變。修改設定後重新建立視窗才讀取位置。
- 不新增同步欄位、RPC、玩法計時或玩家選擇器；保留原圖與 Scene／Prefab 接線。本輪沒有自動調整任何正式版面值或搬移資產。
- 套用前比對來源：設定被別處改過時拒絕套用；現有 UI 比對其原 RectTransform。請關閉草稿後重建。Undo 復原後也應重建，避免沿用過期草稿。
- 草稿子物件不可編輯，只有標示的容器可拖曳；避免誤把自動生成的單個圖示當成正式設定。
