## 已確認玩法與狀態

| 狀態 | 生命／操作 | 流程 |
|---|---|---|
| 健康 | HP > 0，可正常行動 | 致命傷在安全屋外進入倒地 |
| 倒地 | HP = 0、IsDowned=true、IsAlive=false、IsDead=false；低姿慢速爬行、可轉頭，不能跳躍、衝刺、滑鏟、開火、換彈、鈎索或主動技能 | 保留原 NetworkObject，不發 Died；仍在撤離必要名單 |
| 死亡 | IsDead=true；不可救援 | Died 只發一次，由既有 GameLogic 移除角色並銜接觀戰；不在撤離必要名單 |
| 救起 | 同一物件恢復最大生命的 35% | 保留裝備與原有能力冷卻，不重建角色 |

- 倒地不再承受傷害，普通治療不能使其起身。30 秒未獲救即死亡。
- 健康隊友靠近按住 E 五秒救起；顯示救援進度與剩餘秒數。有效救援期間暫停 30 秒倒數。
- 放開 E、超距、隔牆、救援者倒地／死亡／離線或輸入缺失會中斷並歸零。救援者受傷本身不中斷。
- 同一倒地者一次只有一名救援者，多人不加速。救援者可移動／轉頭，超距中斷；救援期間封鎖武器、鈎索及主動能力，避免操作衝突。
- 一次按住 E 取得救援用途後持續消耗至放開；救援完成／中斷不會把同一次按住漏給 E 技能。
- 房內沒有任何健康成員時開始兩秒死亡倒數；健康成員以同 Runner、目前連線且綁定有效角色、IsAlive 為準。較早到期的 30 秒期限仍可先造成死亡；若健康成員出現則撤銷此兩秒期限。
- 全隊倒地不立即宣告關卡失敗；等正式死亡後由 StageFlow 原全員死亡分支處理。成功撤離／失敗返回安全屋沿用既有場景與存檔流程。

## 敵人鎖定

沿用 EnemyPerceptionController 的唯一目標與 EnemyAwarenessBrain，不設玩家五秒隱形／無敵。
倒地當下，原本 CurrentTarget 為此玩家的敵人記錄該物件身分並立刻 ForgetTarget，停止追逐。倒地玩家仍會被 IsValidAlivePlayer 排除。
救起後，原有仇恨等待五秒再將玩家交回原目標入口；正常視野、無牆遮擋且進入該敵人攻擊距離，或原有攻擊警戒／情報來源，都可提前鎖定。延期不授予穿牆開火資格；攻擊仍受既有 CombatSight 與 CombatDecision 仲裁。已死亡、離線或重新生成的不同物件不繼承舊目標記憶。

## 權威與接點

- 不新增 Health 或 Player NetworkBehaviour：在既有 PlayerHealth partial 增加 Networked 倒地、救援雙方、進度、剩餘時間與恢復仇恨期限。Host／Client 必須使用同版程式與 Fusion weave 結果。
- 主要 GameLogic 每 Tick 先處理墜出地圖，撤銷無效救援，再讀各人的 NetInput 意圖，最後統一計時。傷害、救起、期限與死亡都由 State Authority 執行；沒有可由 Client 任意指定救援成功的 RPC。
- Input Authority 僅預測按鍵過濾；HUD 只讀同步結果。碰撞使用對應 Runner 的 PhysicsScene。
- PlayerActionGate 合併倒地／救援封鎖，不清除其他來源。倒地中止既有武器／技能／鈎索與滑鏟動作，沿用既有中斷入口。
- PlayerSlideController 使用原蹲姿膠囊與鏡頭高度，Player 只降低既有 KCC 移動輸入；沒有加入新的爬行動畫素材。
- GameLogic 使用原 RespawnTimers 的 None 項目標示「本關已死，等安全屋」，Reconcile 不可誤補生成；只有正在執行的 Timer 才可到期重生。正式轉場清除此清單，再由原 SceneLoadDone 重建所有連線成員。
- 安全屋由 SafeHouseFlowController.IsActiveFor(Runner) 判定，永遠使用原自動復活。另保留 GameLogic 開關供明確切回舊模式或隔離測試。

## 地圖外判定與 Inspector

使用者選擇「低於地圖底部一定高度即死亡」，健康或倒地都可觸發，不先經過倒地。
GameLogic 優先取人工 Map Bottom Reference 的世界 Y；未指定時從同 Runner 已就緒的 NetworkMapState.Chunks 內啟用、非 Trigger、非動態物件的 Collider bounds 最低 Y 建立快取，LayoutRevision／切場時重建。沒有可用地圖資料時使用本場出生點最低 Y，再回退 Fallback Spawn Position 的 Y。生成地圖的上下層可用人工參考點明確指定期望底部。

| 位置／欄位 | 預設 | 有效值與影響 |
|---|---:|---|
| KCC_Player → PlayerHealth → Downed Lifetime Seconds | 30 秒 | >= 0.1；未受救援時間 |
| No Healthy Member Seconds | 2 秒 | >= 0.1；無健康成員期限 |
| Rescue Duration Seconds | 5 秒 | >= 0.1；連續按住期限 |
| Rescued Health Fraction | 0.35 | 0.01～1；最大 HP 比例 |
| Rescue Distance | 2.5 公尺 | >= 0.1；Root 距離，需無牆遮擋 |
| Crawl Input Multiplier | 0.25 | 0.01～1；另乘原蹲姿倍率 |
| Previous Aggro Delay Seconds | 5 秒 | >= 0；正常偵測可提前覆蓋 |
| Rescue Obstruction Mask | 全層 | 忽略 Trigger 與玩家／敵人 Collider，需包含正式牆壁地板；採樣溢位則不允許救援 |
| 場景 GameLogic → Use Teammate Rescue Outside Safe House | 開 | 關閉沿用自動重生；安全屋不受此開關限制 |
| Fall Death Distance Below Map | 20 公尺 | >= 1；底部以下的容許高度差 |
| Map Bottom Reference | 空 | 可選 Transform；世界 Y 優先於自動估計 |

2.5 公尺、爬行倍率與 20 公尺墜落差是本輪可調初始值，非使用者指定的平衡定案。原有 Scene／Prefab 人工值未覆寫。

## 救援圓環外觀

依 2026-10-16 使用者示意圖：外層為空心圓環，進度為零時完全不畫圓環，由頂端順時針填滿至一整圈，不畫常駐底環；中央方形 E 按鍵只對救援者顯示。倒地者隱藏整個按鍵（背景及 E）；受到救援時顯示「正在被救援」，保留同步圓環與剩餘秒數；未受救援／被中斷時顯示「已倒地 · 等待隊友救援」。

- 沿用既有 `BattleHUD/Layout/LevelRing.png` 空心 Sprite，原生 `Image.Type.Filled / Radial360`，`fillAmount` 直接讀同步 `RescueProgress`，不另跑本機救援時鐘。
- 圓環金色 `#D5C45E`；按鍵奶油白 `#F1EDD9`，字色深橄欖 `#192014`。字型 `NotoSansTC-Bold HUD SDF`，按鍵背景的 Sprite／紙質 Material 均取目前 StageHUD 的技能按鍵。圓環 120×120、按鍵 60×60、E 字級 38；人工調整可直接修改 Prefab 子物件。
- 已透過 Editor 將本輪線形原型遷移為圓環 Prefab；`UpgradeCircularPrototype()` 僅供明確遷移，不會在執行時自動重設人工值。欄位由原型 Slider `progressBar` 改接 Image `progressRing`，本輪唯一原型資產已同步接線。
- [空白／半滿／全滿實際 Unity 渲染](Validation/PlayerRescue/rescue-ring-states.png) 是靜態驗收圖；實際完成救援後 HUD 隱藏，不新增完成停留計時。

1. 已提供獨立 `Assets/Prefabs/UI/PlayerRescueHUD.prefab`；建立工具為 `Purgers/Setup/Create Rescue HUD Prefab`，既有資產存在時不覆寫。
2. 2026-10-16 依使用者要求已接入並保存 `_Menu/GameplayHUD Canvas/PlayerHUDCanvas/ReferenceFrame/PlayerRescueHUD`，場景只有一份。沿用既有 BattleHudReferenceFrame 的 1920×1080 等比例縮放，與主選單 Panel 分離。無須再手動拖入，也無須掛到 KCC_Player。
3. 根 RectTransform 預設螢幕中央下方 180，大小 440×190，以現有 Canvas 1920×1080 比例調整；正式排版請按手感人工調整。
4. LocalPlayerRescueHUD 的 Content、Status、Time、ProgressRing、Key Prompt 已在獨立 Prefab 內接好；Runner 單一觀看端可留空，Multi-Peer 檢查需指定觀看端。
5. 兩人進關：A 致命傷保留本機視角、低姿爬行及 30 秒倒數，B 的怪物繼續正常行動，怪物不再追 A。B 接近按 E，確認五秒圓環、A 倒數暫停及救起 35% HP。
6. 分別驗證 B 受傷不中斷、放鍵／離開範圍／隔牆／斷線中斷。驗證第三人同時按 E 不加速，以及 E 按住直到救起後不觸發技能。
7. A 在撤離區外倒地時必須阻止完成撤離，A 正式死亡後則排除；無健康成員等兩秒死亡。死亡者進既有第一人稱觀戰，返回安全屋後重生。
8. A 復起躲在牆後：原敵人五秒後恢復目標；五秒內主動露出或進可攻擊距離可提早鎖定。地圖外下墜跨過門檻必須立即死亡，即使當時正在被救援。

## 2026-10-16 成長獎勵與技能掉落局部核對

## 2026-10-18 觀戰資格與全滅（局部核對）

倒地尚未死亡的玩家可以被死亡隊友觀戰，Health.IsAlive=false 不再作為觀戰排除條件；須 IsRescueReady 且 !IsDead。正式死亡才移出名單，復起不搶換現有觀戰目標。全員正式死亡（沿用原無健康成員處理後）才由 StageFlow 進全滅轉場，詳見 [100](100_UI觀戰與聊天.md)、[144](144_PrePhase4-1_共用控制與轉場.md)。
