## 授權與本輪接入

使用者要求將先前治療 V1.2、受傷 V1、速度動能增益 V1 套入遊戲。後續依使用者指示將名稱統一為「速度動能增益」，只有量條滿格才顯示；橘金仍僅描述配色。沿這三組外觀參數接入實際資料，沒有加入殘血效果或新的玩法狀態。事件判定、混合與生命週期為本輪實作選擇，待自然遊戲與主觀驗收；沒有自行新增關鍵詞索引定案。

| 效果 | 正式資料來源 | 顯示與停止 |
|---|---|---|
| 治療 | `PlayerHealth.LocalHealingReceived(appliedAmount)` | 只有有效正數實際回血觸發；滿血無回血不顯示。0.10 秒淡入、0.16 停留、0.70 淡出 |
| 受傷 | `PlayerHealth.LocalDamageReceived.AppliedDamage` | 只有有效正數實際扣血觸發；完全格擋／全吸收不出紅色受傷外框。0.035 秒淡入、0.065 停留、0.52 淡出 |
| 速度動能增益 | `PlayerGrappleMomentumEnergy.NormalizedEnergy` | 只有有效 NormalizedEnergy ≥ 1 才以 0.16 秒淡入；未滿時目標為零，離開滿格後以 0.65 秒淡出；不另建充能／保持 Timer，不讀世界速度 |

連續治療或傷害由連續事件自然刷新：每次從目前亮度接續淡入，不瞬間熄滅、不相加；最後事件停止後完整退去。沒有以預覽的固定 3 秒或 0.55 秒 Tick 取代真正玩法。正式單次／連續共用相同峰值，連續包絡由實際事件間距決定；預覽的固定演示時長仍只留在 Editor。

## 本機責任與清除

- 原 `DamageReceiverUtility`／PlayerHealth／RPC 路徑保持；不新增 RPC、Networked 欄位、血量系統或傷害判斷。治療與傷害事件依既有 RPC 只到受影響的 Input Authority。
- `LocalPlayerScreenEdgeEffects` 只綁目前 Runner 的 LocalPlayer PlayerObject，確認 `IsValid`、`HasInputAuthority`，並通過 `PlayerHealth.IsRescueReady` 的 Spawned 生命週期保護後才讀生命與動能。
- 無明確 Runner 時，每 0.25 秒只接受唯一正在運行、ProvideInput 且 LocalPlayer 有效的 Runner；多 Peer 不猜來源。`Configure(settings, runner)` 可明確指定驗證或特殊客戶端。
- 只呈現自己；不從觀戰對象的 HP 差值猜測受傷或治療。死亡、倒地、無有效本機對象、場景載入、斷線、停用及換人立即清除；重新綁定不重播舊事件，持續動能從新快照重新顯示。
- 新外框具有效 Shader／設定且接管同一 Health 時，`PlayerAbilityColorGrading` 僅抑制舊治療 LGG。其他技能與保命調色保留；外框停用、缺少或治療強度為零時回復既有治療 LGG。

## 合成與 HUD

共用一個 `ScreenEdgeGraphic`／子 Canvas／執行期 Material，無全畫面 RenderTexture、額外相機或後處理 Feature。正式 Shader 直接輸出透明外框，完全沒有歷史截圖、HUD 座標或色彩遮罩。

權重先依優先權壓低：受傷保留自身權重；治療乘上 `1 - 受傷 × suppression`；速度動能增益乘上 `1 - max(治療,受傷) × suppression`。再依速度動能增益 → 治療 → 受傷做 Alpha 合成，總不透明度封頂 0.75。預設 suppression 0.75，故三者都滿時權重是 (治療 0.25, 受傷 1, 速度動能增益 0.25)。權重不是網路狀態，不回寫玩法。

正式配置：`_Menu / GameplayHUD Canvas / PlayerHUDCanvas / ScreenEdgeEffects`，Prefab 為 `Assets/Prefabs/UI/ScreenEdgeEffects.prefab`。獨立子 Canvas Order = **-5**，高於護目鏡 -10、低於玩家 HUD 0 與 StageHUD 100；全畫面 Stretch，位於 ReferenceFrame 外。Graphic 不接收 Raycast，CanvasGroup 不互動／不阻擋，沒有 GraphicRaycaster。

Shader 數學與 Editor 預覽共用 `Assets/Shaders/Presentation/ScreenEdgeEffectsCore.cginc`，避免兩組外觀各自漂移。預覽 Shader 仍可使用歷史截圖遮罩；正式 Shader 不含該遮罩。正式網格為四個矩形（16 頂點／8 三角形），中央保留空洞，穩定狀態不逐幀重建。速度動能增益現只保留柔光外框與輕微明暗呼吸，已移除向外移動的 32 條流線；治療仍由 Shader 程序生成最多 14 個十字，沒有新增貼圖。此成本描述不等於已量測 GPU 效能。

## Inspector 設定

選取 `Assets/Resources/Presentation/ScreenEdgeEffects.asset`；Prefab／Scene 直接引用此資產及正式 Shader，Build 不依賴 Editor Shader.Find。

| 設定 | 治療 | 受傷 | 速度動能增益 |
|---|---:|---:|---:|
| RGB | (0.30,0.95,0.64) | (0.96,0.16,0.10) | (0.1462264,1,0.85263824) |
| Strength | 0.52 | 0.66 | 0.35 |
| Width | 0.105 | 0.15 | 0.067 |
| Vertical Width | 0.075 | 0.115 | 0.075 |
| Corners | 0.55 | 0.50 | 0.60 |
| Symbols | 12 | 0 | 0 |
| Fade In／Hold／Fade Out | 0.10／0.16／0.70 | 0.035／0.065／0.52 | 0.16／不使用／0.65 |

`Effects Enabled` 整組開關；`motionRate` 僅保留舊序列化相容，已隱藏且不再影響畫面；`Maximum Opacity=0.75` 限制合成遮擋；`Priority Suppression=0.75` 調狀態搶占。個別 Strength=0 隱藏該效果。寬高是視窗比例，不改原 HUD 位置或尺寸。

`Tools > Purgers > UI > Create And Wire Screen Edge Effects` 為冪等配置工具；只在乾淨且已載入的 _Menu 新增缺少的元件，保留既有人工值。首次配置核對 1794 個既有元件序列化快照一致後才保存。不主動選取、聚焦或切場景。
